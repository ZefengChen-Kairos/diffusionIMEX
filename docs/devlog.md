# C. 开发记录：测试中遇到的问题与逐版修改

本页记录 `src/SPB6_TV_IMEX.cpp` 从第一版到当前版本的全过程：每一版跑了哪些测试、出现了什么现象（带数字）、试过哪些假设（包括被否定的）、根因在推导的哪一步、怎么改的、改完怎么验证。推导本身见 A、B 两页（仓库 `docs/derivation/`）；这里只记“为什么改成现在这样”。

原则（来自你的要求）：测试对不上时，先查推导、重读论文、查代码，找到数学上的原因再改，不靠补丁。下面每一处修改都对应推导里的一个具体结论（B 节号在括号里）。凡是“只为让算例跑通”的改动，都已撤掉或标为对照开关。

记号：IMEX 默认 $N=1000$、二阶、物质 CFL 0.2、`rk=2`（LSDIRK2）；显式参考（MODE 0，SPB 原格式）声学 CFL 0.4–0.5。“v23”指你给的 handoff 里前一个 agent 的 `spb_imex.cpp`，作为基线。

## V1 → V2：第一次提交前的四处修正

### 1. 微量相 $\alpha$ 变负：BB 的格均值中心通量不是 TVD（B3）

- **现象。** 第一次运行 SPB 4.1（$N=200$，二阶，`rk=2`），两种模式都失败：
  - IMEX 第 4 步失败，$\alpha_2$ 最小值 $6.0\times10^{-12}$（初值 $10^{-8}$），`Newton failed: it 0 res inf`；
  - 显式第 32 步失败，$\alpha_2$ 最小 $-2.7\times10^{-10}$。
- **推导。** 对线性输运 $X_t+uX_x=0$（$u>0$），中心部分用格均值的 Rusanov 通量是 $F=\tfrac12u(X_i+X_{i+1})-\tfrac12u(X^R-X^L)=uX_i+\tfrac14u(\sigma_i+\sigma_{i+1})$。它含下游格的斜率 $\sigma_{i+1}$，不是 TVD，微量相界面处会产生负值。
- **修改。** 中心部分也用重构面值：$F=\tfrac12(X^Lu^L+X^Ru^R)-\tfrac12a(X^R-X^L)$，$u^{L,R}=(\rho u)^{L,R}/\rho^{L,R}$。对线性输运这就是 MUSCL 迎风通量 $u(X_i+\tfrac12\sigma_i)$，仍是二阶。BB 的形式留作对照开关 `cavg=1`。
- **验证。** $\alpha_2$ 保持在 $[10^{-8},1]$。但一阶也还失败，说明还有第二个错误。

### 2. 均匀压力下 $G=-4.56$ Pa：`closure_p` 在 $\Phi=0$ 恰为零时的终止错误（B6.1）

- **现象。** Newton 停在相对残量 $4.56\times10^{-5}$。离界面很远、$P\equiv10^5$ 的格子 $G=-4.56$ Pa，而 WB 证明（B9.1）说这里应该 $G=0$。
- **排除的假设。**
  - 增量供体在 $\Delta u_f=0$ 处的折点破坏差分 Jacobian：否定，残量本身就不为零。
  - 能量差 $D_0$ 不一致：否定，$D_0=5.7\times10^{-8}$，是舍入。
  - 闭合公式错：否定。自检（`SELFTEST=1`）在初猜 $10^4$ 到 $10^7$ 之间都返回 $10^5$。
- **定位。** 把出错格的输入按全精度导出，用 Python 重算：$\Phi(99995.436)=1.7\times10^{-9}$，精确根是 99999.99999983766。所以返回值不是根。
- **根因。** 迭代中 $\Phi(p)$ 恰好等于 0 时：
  1. 先执行了区间更新 `hi = p`；
  2. 于是 Newton 新点 $p_n=p$ 不在开区间 $(lo,hi)$ 内，被换成区间中点；
  3. 停止条件 $|f|<10^{-16}$ 又接受了这个中点。
  
  返回值 $(99990.872+99999.99999970)/2=99995.436$，正是出错值。打印的迭代轨迹是替换前的 $p_n$，所以看起来已经收敛。
- **修改。** $f=0$ 时直接返回；停止条件改为步长或区间宽度到机器精度。
- **验证。** WB：$\max|p/p_0-1|=2.7\times10^{-10}$，$\max|u-100|=8\times10^{-10}$（v23 为 $1.4\times10^{-7}$）。显式 SPB 4.1 也通过（$6.2\times10^{-10}$），它在第 1 节里的失败也是这个错误。

### 3. 1 GPa 水–气：气体格 $(\rho e)^C<0$，密度加权面压力（B4.1(a)）

- **现象。** SPB 4.3.1 的 IMEX 第 25 步失败：第一个气体格的守恒内能 $(\rho e)^C=-1.18\times10^7$，减半 $\Delta t$ 无效。
- **推导。** 面速度用面密度 $\bar\rho_f$ 加速，格动量却用格密度承受面压力差 $\tfrac12(P_L+P_R)$ 的差分。密度比 1000:1 时，轻格的动能与面上的功不匹配。由“面两侧各半格以同一加速度运动”的半格动量平衡得
  $$p_f=\frac{\rho_RP_L+\rho_LP_R}{\rho_L+\rho_R}.$$
  于是格速度的压力增量恰为两侧面增量的平均，均匀 $P$ 时仍有 $p_f=P$（WB 不变）。
- **验证。** 4.3.1 算完：$L_1(u)=7.39$，气体最大速度 537（精确 492；v23 为 614），激波 0.947（精确 0.935；v23 为 0.978）。WB $2.3\times10^{-10}$。

### 4. `root_above` 在初猜恰为根时失败（B6.3–B6.6 共用的求根）

- **现象。** 试验等熵闭合（见下）时，WB 在 $t=0$ 就失败，自检返回 $p=0$。
- **根因。** 区间搜索要求严格变号，初猜恰为根时 $f=0$，找不到区间。
- **修改。** $f_0$、$f_a$ 或 $f_b$ 为 0 时直接返回该点。这同时修正了 $pT$、$\theta$、$\nu$、$pTg$ 闭合。

### 被否定的假设：后向 Euler 闭合不等熵（`isen` 对照开关）

- **背景。** 十二烷算例（只 $p$ 松弛）IMEX 的稀疏区压力远低于参考：$\min p=1.4\times10^4$，参考 $1.27\times10^5$；$L_1(p)/10^5=10.7$，显式 1.54。假设是离散 Gibbs 关系 $\varepsilon_k-\varepsilon^{\rm tr}_k=-p(\alpha_k-\alpha^{\rm tr}_k)$ 只是等熵线的一阶近似。
- **试验。** 实现各相沿精确等熵线 $(p+\pi)(\alpha-mb)^\gamma=C_k$ 的闭合（`isen=1`）。
- **结果。**

  | 算例 | 后向 Euler 闭合 | 等熵闭合 |
  |---|---|---|
  | 十二烷 `rk=2` | $L_1(p)/10^5=10.7$ | 9.6 |
  | 4.3.1 | $L_1(u)=7.39$ | 15.9（更差） |
  | 4.5 中心 $p$ | 3.14 | 3.15 |

- **结论。** 不是主因。默认仍用后向 Euler（它就是推导 B6.1 的离散 Gibbs 关系），`isen` 只作对照。真正的原因在 V3 找到（下面的 3.2 节）。

**(2) 增量供体的相间逆流（修正了，但不是原因）（B4.2'）。**

**(4) 变体 A：半格质量取声学影响域 $\rho\min(c\tau,\Delta x/2)$（试过，舍弃）。**
- 思路：面两侧参与动量平衡的质量取声学影响域。$\tau\to0$ 时就是声学 Godunov，$\tau$ 大时回到半格平衡。
- 好的一面：十二烷平台 $L_1(p)/p^*$ 从 0.449 降到 0.060（显式 0.058）；水–气 CFL 0.05 能算完。
- 坏的一面：空化管变坏，中心 $p$ 为 $5.8\times10^3$（`rk=1`）和 $1.4\times10^4$（`rk=2`）。

**(5) 变体 B：把声学耗散补足到 Godunov（采用）（B4.1）。**
- 保留原来的面量，在 $u_f$ 上加压力扩散项 $\varphi\Delta P/(Z_L+Z_R)$，在 $p_f$ 上加速度跳跃项 $\varphi\frac{Z_LZ_R}{Z_L+Z_R}\Delta u$，权重 $\varphi=(1-\tau\min c/\Delta x)^+$。

  |---|---|---|
  | 十二烷平台 $L_1(p)/p^*$ | 0.026 | 0.041 |
  | 水–气 $\max u/u^*$ | 1.035 | 1.109（激波超前约 20 格） |

**(6) 为什么需要补足：von Neumann 分析（`tools/vonneumann_*.py`）。**
- 最初的理由是“后向 Euler 的声学耗散 $c^2\tau/2$ 在 $\nu<1$ 时不足 Godunov 的 $c\Delta x/2$”。分析表明这个说法**不对**：低波数时隐式步的等效耗散已不低于 Godunov。

  - 本步各级冻结闭合类型；
  - 有限速率不投影。

  这就是 P-S 的算子顺序（双曲步之后判断并松弛），只是松弛放到下一步开头。
- **结果。** 所有失败的算例都算完：

### 4.1 `closure_mu` 的根区间（B6.2）

- **现象。** $\mu=10^{-2}$ 的 0D 运行卡住（10 分钟）。复现时每一步都要减半 20 次，在 $\Delta t=9.5\times10^{-12}$ 时才被接受，然后下一步又从 $10^{-5}$ 开始。$\mu=10^{-4}$ 有 106 万次拒绝。
- **根因（推导）。** 旧代码把 $\mathcal F(R)=R-\tau\mu(p_1-p_2)$ 的区间取成体积可容许区间的端点 $(-(a_1-m_1b_1),a_2-m_2b_2)$。但被压缩相的功按终态 $p_I$ 计（后向 Euler），2×2 方程组在该相体积到零之前就奇异（SG、$p_I\approx p_2$ 时在 $R=a_2/\gamma_2$），$\mathcal F$ 在端点不定号。
- **修改。** 松弛使 $|p_1-p_2|$ 减小，所以根在 0 与 $R_1=\tau\mu(p_1-p_2)|_{R=0}$ 之间。$R_1$ 不可容许时，奇点处 $\mathcal F$ 趋于正确符号的无穷，向 0 二分即可。
- **结果。** $\mu=0$ 到 $\infty$ 都是 10 步、0 次拒绝；$\mu\ge10^{-4}$ 时 $p_1=p_2$。

### 4.2 `theta=0` 被当成 $\infty$（代码逻辑）

- **现象。** $\theta=0$ 时 $T_1=T_2$（应保持不等）；有限 $\theta$ 的误差停在 $5.2\times10^{-4}$，收敛阶约为 0（参考态本身就成了热平衡态）。
- **根因。** 默认值 0 同时表示“未给定”，主程序把 0 换成了 $\infty$。
- **修改。** 用 $-1$ 表示未给定，默认值按松弛档位取。
- **结果。** $\theta=0$ 时 $T_1=349.99$、$T_2=380.01$；有限 $\theta$ 二阶收敛。

### 4.3 `closure_nu` 的内层区间越出 $T>0$（B6.5）

- **现象。** 算例 41 在 $\nu=10^{-4},10^{-3},10^{-2}$ 下的输出与 $\nu=0$ 完全相同。原因是程序在第 0 步就失败了，输出的是初值。
- **根因（推导）。** 内层 $Y$ 区间取 $[Y_{\min},1-Y_{\min}]$。能量固定时 $T(p,Y)>0\iff Y<(e-q_1)/(q_2-q_1)$，区间的一部分 $T\le0$，残量为 NaN，闭合失败。
- **修改。** 区间取可容许部分。$T\to0^+$ 时 $g_k\to q_k+b_kp$，$\mathcal R$ 在该端的符号与单调性一致，所以根仍唯一。
- **结果。** $\nu$ 从 0 到 $10^{-1}$ 单调变化，AP：$|p-p_\infty|=O(1/\nu)$。

### 4.4 刚性中间区：LSDIRK2 越过平衡（B10，记录，未改代码）

- 二阶方法不可能对所有 $z$ 都单调（Bolley–Crouzeix），后向 Euler 单调。
- 结论：速率刚性但有限时用瞬时闭合（AP 保证其为极限）或 `rk=1`。

### 6.1 显式参考格式把有限速率松弛放大约 2 倍（A3 的推导错）

- **现象。** Pelanti 8.2.1（$N=5000$）中，只有 $p$ 松弛时显式与 IMEX 的中心压力一致（4803 / 4795 Pa），$pT$ 也一致（13688 / 13683）。但有限速率 $pT(f)$（$\vartheta=2000$）差 19%：显式 10556，IMEX 8849；中心汽相温度显式 328 K，IMEX 276 K，显式松弛得更多。
- **先排除 IMEX 的时间离散。**
  - 中心汽相热容 $C_{p2}=\gamma_2c_{v2}m_2\approx8$ J/(m³K)，松弛率 $\lambda\approx\vartheta/C_{p2}\approx250$ s⁻¹，即松弛时间约 4 ms，与算例时间 3 ms 同量级。
  - IMEX 的 $\lambda\Delta t\approx0.005$，不刚性，后向 Euler 的误差约 0.25%。
  - 0D 测试也给出 IMEX 对有限 $\vartheta$ 二阶收敛。
- **根因。** A3 写的是“二阶：MUSCL + Heun，每一级之后都做松弛”。代码照此在 Heun 两级之后和平均之后各做一次 $\tau=\Delta t$ 的松弛。对松弛 ODE $y'=-\lambda y$，记 $R$ 为步长 $\Delta t$ 的后向 Euler，这一步是
  $$R\Big(\tfrac12\big(y+R(R(y))\big)\Big)=(1-2\lambda\Delta t)\,y+O(\Delta t^2),$$
  速率被放大 2 倍。
  - 瞬时松弛是投影，幂等（$P\circ P=P$），每一级都做没有问题。
  - 有限速率是对时间的积分，每步只能做一次。
- **0D 验证。** 算例 40，$\vartheta=5\times10^6$，一个显式步。对数衰减率与小步长 IMEX 参考之比：

  | | 修改前 | 修改后 |
  |---|---|---|
  | 二阶 | 1.93 | 0.975 |
  | 一阶 | 0.975 | 0.975 |

  0.975 就是后向 Euler 单步的 $\ln(1+z)/z$。
- **修改。** Heun 的两级之后只做瞬时部分：$\mu=\infty$ 的力学投影；有限 $\nu$ 时做 $pT$ 投影（因为此时 $\theta=\infty$）。有限速率每步只在平均之后做一次。这是 Lie 分裂，与 Pelanti §7 的算子顺序相同（论文的算法正是每步一次）。A3 同步改正。
- **影响范围。**
  - 瞬时松弛的显式算例逐位不变（5 个算例 `cmp` 相同）；
  - IMEX 不受影响；
  - 作废的只有显式的有限速率结果（Pelanti 8.2.1 的 $pT(f)$、$pTg(f)$）。

### 6.2 IMEX 显式部分的 Rusanov 耗散速度必须不小于面态速度（B3 的推导错）

- **现象。** 水–气（SPB 4.3.1）用 `rk=1`（后向 Euler）从来没有算完过：V2、V3 的两次测试集都没有结果，这次的运行用了 32 分钟 CPU 仍在跑。

## V8 二维检查：IMEX 中 y 向均匀的问题各行发散

你要求“代码要是二维的”，而 B11 写着“二维路径未经验证”。最基本的二维检查：把一维算例放在 $N\times4$ 的网格上（y 向透射边界、初值 y 向均匀、$v=0$），每一行都应与一维结果相同，$v$ 恒为 0。

### 8.1 现象

$N=200$，$n_y=4$，各算例的终止时间：

| | 显式 | IMEX（V7） |
|---|---|---|
| 各行之间 | 逐位相同，$v\equiv0$ | SPB 5.1：行间压力差 $2\times10^8$ Pa（$p^*$ 的 4%），$\max\lvert v\rvert=0.37$ m/s；SPB 4.3.1：$\max\lvert v\rvert=1.07$ m/s |
| 与一维比 | 间断处差 3%：二维的时间步含 $c/\Delta y$，步长不同 | 同左，另加行间差 |
| 守恒误差 | 与一维相同 | 4.3.1：$dM_1/M$ 从 $6.9\times10^{-7}$ 变为 $8.4\times10^{-6}$ |

IMEX 的行间差在第 1 步只有舍入大小（$6\times10^{-4}$ Pa，$p\sim10^{10}$ Pa），第 4 步已是 $9\times10^5$ Pa。

### 8.2 排查

1. `order=1` 时行间差保持舍入大小，所以原因在二阶部分。
2. 依次关掉 y 向重构、y 面的 $\psi$、y 面的声学补足、x 面的 $\psi$：行间差都不消失。所以不是 y 向的离散。
3. 诊断：令所有行都用第 0 行的 x 向共用限制因子 $\phi$，行间差保持 $1.7\times10^{-3}$ Pa（舍入）。所以原因是各行的 $\phi$ 不同。
4. 打印各行 $\phi$ 不同的格，触发 $\phi=0$ 的量是：
   - $\rho u$、$\rho v$，取值 $10^{-38}$–$10^{-11}$：静止区的 $\rho u$ 和横向动量 $\rho v$ 的舍入噪声；
   - 有微量相的算例中还有微量相的 $\alpha$、$\varepsilon_k$。
5. 用按舍入尺度的判据（根因 1）之后，没有微量相的算例（SPB 5.1、光滑解）各行一致到舍入。有微量相的算例（4.3.1）行间差在前 7 步保持 $10^{-11}$–$10^{-9}$，第 11 步跳到 $4\times10^{-3}$：某个真实极值处的限制器开关被行间的微小差别提前或推后了一步。所以还要让各行的舍入本身相同（根因 2）。

### 8.3 根因与修改

**根因 1（推导，B3）：共用限制因子的“模板内为常数（到舍入）”判据用了各量自身的大小。** 原判据是 $|a|,|b|\le10^{-12}(|x_a|+|x_c|+|x_b|)$，但格式产生的舍入并不都相对于该量自身：

- $\rho u$、$\rho v$ 由压力差驱动，舍入 $\sim\varepsilon_{\rm mach}(\tau/h)p\sim\varepsilon_{\rm mach}\rho c$，与当地 $|\rho u|$ 无关。一维中 $\rho v\equiv0$，判据总是跳过它；二维中隐式 y 面的压力在最后几位不同，$10^{-15}$ 的噪声就触发极值判据（$ab\le0$），使该格所有量的 $\phi=0$。静止区（$u\approx0$）的 $\rho u$ 同理。
- 微量相 $\alpha$（$10^{-6}$–$10^{-8}$）的舍入来自 $\sum\alpha=1$，是 $\varepsilon_{\rm mach}$，而不是 $\varepsilon_{\rm mach}\alpha$。
- $\varepsilon_k$ 被闭合的 $p\,d\alpha$ 在两相间搬运，舍入相对于混合物内能。
- 原判据对动量也不是旋转不变的：同一流动转 45° 后两个动量分量都大，判据就不触发。

修改：按各量的舍入尺度判（B3 的表）：

- $\alpha_1$：1；
- $\rho u$、$\rho v$：$|\rho\mathbf u|+\rho c_f$；
- $\varepsilon_k$、$E$：$\sum|\varepsilon_k|+\tfrac12\rho|\mathbf u|^2$；
- $m_k$：仍用自身大小。无传质时 $m_k$ 只被自身通量输运，舍入相对于自身；这也是微量相质量保正所需。试过 $m_k$ 用 $\rho$：十二烷 $p$ 松弛的平台误差从 0.043 变为 0.048，而且对 $10^{-8}$ 的微量只剩 13 倍保正余量，所以不用。

**根因 2（实现，B8）：边界行的 Jacobian 把虚格压力并进了对角元。** 透射边界的虚格压力等于本格压力。V7 求对角元的差商时让虚格跟着本格一起扰动，所以边界行只有 4 个元素（对角元含虚格的贡献），内部行有 5 个。数学上两者相同，但浮点运算不同：BiCGStab 的解在边界行与内部行之间有舍入差，第 1 步后各行就不再逐位相同。共用限制因子是数据的不连续函数（极值判据），舍入差在某个格翻转判据后变成截断误差大小的差，再经 y 向的压力耦合产生 $v$。

修改：

- 虚格压力在 Jacobian 中是单独的元素，列号为本格；
- 每行按“本格、W、E、S、N”的固定次序存放，同列也不合并；
- Jacobi 预条件用本格扰动的那个元素；一维 Thomas 把同列元素相加。

Jacobian 在数学上不变。

三个问题：

1. **$M=0.1$ 时补足项是声速量级的粘性。** $\varphi=1-a_{ii}\mathrm{CFL}/M=0.41$。速度项乘局部马赫数后升到 0.49，与 $M=0.01$ 一致。

### 11.3 根因

**(a) 推导（B4.1(c)）：速度跳跃项按维度作用在法向跳跃上。**
- 低马赫分析：压力扩散项对面速度的修正相对 $O(M)$，无害；速度跳跃项在动量里是 $c\Delta x$ 量级的粘性，相对 $O(1/M)$，这是 Godunov/Roe 型格式的低马赫缺陷。
- 一维里没有这个问题：一维的不可压极限是 $u$ 均匀，$\Delta u=O(M^2)$。
- 二维里逐维的法向跳跃 $u_{i+1,j}-u_{i,j}\approx\Delta x\,\partial_xu$ 对无散的涡不为零。声学子系统只通过散度看见速度，涡在它的核里，声学耗散不应作用在涡上。

**(b) 推导（B3）：共用限制因子在多维涡里把速度降为一阶。** $\phi_i$ 取所有量的最小。$\rho u=-\rho v_\theta y/r$ 沿 $x=0$ 取极值，$v$ 恰在梯度最大处被降为一阶。共用的理由（WB）只涉及经 EOS 相关联的 $\alpha,m,\varepsilon$。这一项与 $M$ 无关，不破坏 AP，但它是 $M\le0.01$ 时 0.50 的来源。

**(c) 实现（B8）：Newton 的残量判据没有考虑舍入底。** $P$ 的舍入经面速度、体积通量与闭合放大 $\nu^2$ 倍（$\nu=c\tau/\Delta x\approx60$）。$M=0.001$ 时残量一步就降到 $(1\text{–}2)\times10^{-13}$（$|G|\approx6\times10^{-7}$ Pa，$P=7.1\times10^5$），高于容差 $10^{-13}$，线搜索降不下去。

### 11.5 修改

1. **速度项改为散度形式（B4.1(c)）。** 二维中 $D^*_f$ 是面两端两个顶点散度的平均乘 $\Delta x$；顶点散度是四格双线性插值的散度。
   - 一维与 y 向均匀时逐位退化为 $u_{i+1}-u_i$：一维结果与 V10 的补足项完全相同，V3 的理由照旧成立。
   - 动量里它是 grad-div（体粘性）：周期、$\Delta x=\Delta y$ 时动能耗散恰为 $-\varphi\psi\tilde Zh^2\sum_v\mathrm{div}_v^2$（$16\times16$ 随机场上数值验证到 $10^{-15}$）。

   - 灵感来源：Guillard–Viozat、Dellacherie 的低马赫分析；Dellacherie–Omnes–Rieper（笛卡尔网格几何）；Morton–Roe 的 vorticity-preserving 格式与 Barsukow 的 stationarity-preserving 格式；von Neumann–Richtmyer。
2. **速度单独重构（B3）。** 体积输运量 $(\alpha_1,m_1,m_2,\varepsilon_1,\varepsilon_2)$ 共用限制因子；$u,v$ 各自 minmod；面上组装 $\rho u=\rho^fu^f$，$E=\sum\varepsilon^f+\tfrac12\rho^f|\mathbf u^f|^2$。
   - WB：均匀 $\mathbf u$ 时面速度就是 $\mathbf u$。
   - 保正：面速度在相邻格速度之间。
   - 灵感来源：`2DEuler_TV.cpp` 对原始变量逐个限制；BB (33)–(34)。
3. **Newton 步长判据（B8）。** 完整 Newton 步 $\max|\delta P|/(|P|+K+P_E)<10^{-13}$ 时接受 $P+\delta P$。有限精度下 Newton 法的标准判据。
4. **没有改的：** 压力扩散项（$O(M)$，无害，而且是十二烷的主要稳定来源）；显式耗散速度仍取全局物质速度（BB (27)，`2DEuler_TV.cpp` 的 `Global_Diss`）。局部速度在 Gresho $M=0.01$ 上从 0.94 升到 0.97，但偏离了这两个出处，不用。

### 11.8 直接检验 AP：同一个 $\Delta t$，$M=10^{-1}\ldots10^{-6}$（你的问题：“这个能修好吗”“保持 AP 是底线”）

11.6 的表用的是物质 CFL 定步长（带起步斜坡），步数随 $M$ 不同。AP 的定义要求的是：$\Delta t$ 与 $M$ 无关时格式一致稳定，且解收敛到不可压极限。所以改用固定步长 `dt=0.0025`（不用斜坡，503 步），$80^2$，算例 50–55（$M=10^{-1}\ldots10^{-6}$），同一个程序、同一套设置。$M=10^{-6}$ 时 $\nu=c\tau/\Delta x\approx5.9\times10^4$。

这样检验发现了三个与 $M$ 有关的问题。三个都在求解器里，离散格式本身（B4、B5）一个字没改：精确算术下改前改后的离散解相同。

**(a) 舍入抵消（$M=10^{-4}$）：压力未知量是绝对压力。**
- 现象：$M=10^{-4}$ 时压力有约 $3\times10^{-3}$（以 $\rho U^2$ 为单位）的格点噪声，$\max|\rho-1|/M^2$ 从 0.10 升到 0.24，压力的 Cauchy 差（$M$ 与 $M/10$ 之差）反而从 $3.9\times10^{-4}$ 升到 $2.8\times10^{-3}$。改 Newton 容差（$10^{-15}$）结果逐位不变，所以不是容差。
- 根因（实现，B8）：存下来的 $P\approx p_0=1/(\gamma M^2)$ 带 $\varepsilon_{\rm mach}p_0$ 的舍入，面速度用 $P_R-P_L$、动量用 $p_{f,e}-p_{f,w}$，这个舍入经隐式算子放大 $\nu^2$ 倍：噪声约 $\nu^2\varepsilon_{\rm mach}p_0\sim\varepsilon_{\rm mach}/M^4$。
- 修改：Newton 的未知量改为 $P-P_{\rm ref}$（$P_{\rm ref}$ 为初始混合压力的最小值），只在能量通量与闭合里加回 $P_{\rm ref}$（B8“扰动未知量”）。精确算术下与原格式相同。
- 灵感来源：Klein 1995 的低马赫多尺度展开 $p=p_0+M^2p_2$；Sesterhenn–Müller–Thomann 1999 以压力扰动为未知量。

**(b) 差分 Jacobian 的步长（$M=10^{-5}$）。**
- 现象：$M=10^{-5}$ 时每步被拒绝两次（4019 次拒绝，2011 步，等于 $\Delta t/4$）。
- 根因（实现，B8）：步长 $h=10^{-7}(|P|+1)$ 在本格引起的体积变化约 $10^{-7}\nu^2/\gamma$，$M=10^{-5}$ 时为 $O(1)$：扰动后的状态已不在线性区，差分 Jacobian 失效。
- 修改：$h=10^{-7}s$，$s=N/D$ 是“残量尺度 / Jacobian 对角元尺度”，即残量所能分辨的压力变化（B8“$P$ 的自然尺度”）。体积变化与导数的舍入误差都与 $M$ 无关。
- 灵感来源：差分 Jacobian 按变量的典型尺度取步长（Dennis–Schnabel）；这里的典型尺度由 B8 的单调性分析（对角元 $\approx1+2d\nu^2$）给出。

**(c) 线性解法（$M=10^{-6}$）。**
- 现象：$M=10^{-6}$ 时 37 次拒绝，都是 BiCGStab 发散（相对残量 $10^{129}$）。
- 根因（实现，B8）：面速度与动量只依赖压力差，常数平移只使 $G$ 变化 $O(1)$，而对角元约 $1+4\nu^2$；Jacobi 预条件后常数模态的特征值约 $1/(4\nu^2)\approx10^{-10}$。
- 修改：两级预条件，Jacobi 加常数向量的粗空间校正 $M^{-1}r=D^{-1}r+\mathbf 1(\mathbf 1^{\rm T}r)/(\mathbf 1^{\rm T}J\mathbf 1)$（B8）。预条件后的谱与 $M$ 无关。各格加的是同一个数，y 向均匀问题的逐位对称不变。
- 灵感来源：Nicolaides 1987 的 deflation / 两级预条件（粗空间取算子的近零空间）；Tang–Nabben–Vuik–Erlangga 2009 的比较。

**(d) 步长判据的尺度（$M=10^{-6}$）。**
- 现象：(c) 之后 $M=10^{-6}$ 的日志终残量 $6\times10^{-12}$，高于容差 $10^{-13}$：步长判据在第一步就接受了一个没有收敛的迭代。
- 根因（实现，B8）：V11 的步长判据用残量尺度 $|P|+K+P_E$ 衡量 Newton 步。低马赫时这个尺度比 Newton 步能改变的量 $s$ 大约 $\nu^2$ 倍，第一步（$3\times10^{-4}$ Pa）就被当成收敛，而一步之后残量的二次项还有约 10 Pa。
- 修改：步长判据用 $|P-P_{\rm ref}|+s$（未知量本身的大小与残量的分辨率）。舍入底的情形照样成立，真正的修正不再被当成收敛；非刚性时与原判据相同。改后各马赫数的终残量都不超过容差（$M=10^{-6}$ 为 $9.3\times10^{-14}$），每级 Newton 从 1.00 次变为 1.02 次。
- 对结果的影响很小（$M=10^{-6}$ 的速度、压力 Cauchy 差不变）：$M=10^{-6}$ 剩下的噪声来自容差本身，见下面结果之后的说明。

## V12 Mie–Grüneisen 状态方程（你的要求：“继续做 MG 状态方程和 2d 算例”）

### 12.1 推导（A2.1、B6.1）

- Cochran–Chan（SPB §4.2）与 JWL（Pelanti §4.2）都是 $p=\Gamma\rho(e-\varepsilon_r(\rho))+p_r(\rho)$，$\Gamma$ 常数，参考曲线是等熵线 $\varepsilon_r'=p_r/\rho^2$（两者都直接验证，数值差 $10^{-8}$）。所有公式只用这一条：声速 $c^2=(\Gamma+1)(p-p_r)/\rho+p_r'$（与差分 $c^2=p_\rho+pp_e/\rho^2$ 相对差 $6\times10^{-9}$），混合压力就是 Pelanti (28)，相 Hugoniot 对 $p^*$ 仍线性（A2.8）。
- 力学闭合（B6.1）：MG 相的 $\alpha_k(p)$ 不再显式，是 $f_k(\alpha)=0$ 的根，$f_k'=\rho_kc_k^2/\Gamma_k>0$，单调、唯一。外层 $\sum\alpha_k(p)=1$ 用带区间的 Newton。
- WB 的条件：(E1) 对 MG 不成立，但每相密度在界面两侧相同时 $\varepsilon_k$ 对 $\alpha_k$ 线性，WB 照旧。SPB 4.2 把同一流体当两相、各相密度均匀，正是为此（SPB §3.2.2 末）。
- MG 相只做力学松弛（两篇论文的 MG 算例都只有力学松弛）；与热、化学松弛组合时闭合报错，不静默。

### 12.2 实现

### 14.2 问题 4、5：±500 m/s $pTg$ 的起步加热与 SPB 4.5 的扇区误差

### 15.7 为什么会拒绝（你的问题）
- 拒绝 = 一步在二阶（LSDIRK2）与同步长一阶（MOOD）下都不可容许（某相质量或能量为负、闭合无解、Newton 不收敛），步长减半重算。
- 最终代码的一维存档里只有两处：
  - SPB 4.3.2 的 6 次：都在 $t=0$ 的第一步。1 TPa 对 $10^5$ Pa（压力比 $10^7$）：交界格的 Newton 从初值压力出发 12–16 次迭代后仍不收敛（线搜索中闭合在交界格不可容许）。减半 4–6 次（$6\times10^{-9}\to1\times10^{-10}$）后收敛，之后不再拒绝。是强间断起步时 Newton 只有局部收敛性。
  - Pelanti 8.2.2 $pTg$ 的 6 次：都在 $t=77\,\mu$s 的一步。上一级的压力作初猜时相变前沿的一个格闭合无解，Newton 第 0 次迭代就失败。
- 为什么先 MOOD 再减半：(1) 减半后步长每步至多放大 1.2 倍，被限制的步用一阶（起步斜坡），一次减半带来约 4 个一阶步；MOOD 只有一个一阶步、步长不变。(2) V14 十二烷的不可容许来自 LSDIRK2 第二级 $Q^s\neq Q^e$（B3 的保正论证不成立），这个偏差与推进量同比例随 $\Delta t$ 缩小，减半不消除原因；后向 Euler 一级 $Q^s=Q^e$，保正在原步长下就成立。(3) 一阶步的个数与网格无关时全局仍是二阶；随网格增长（修 15.2 之前的涡）才掉阶。

## V16 能量亏损的分配由模型的激波关系 (II.5) 决定（你的要求：“理论正确要先优于实验正确 如果 Hugoniot 分配方案是物理上更对的 我们就要用它 如果不对 就继续推导”“继续推导”）

### 16.1 问题：为什么会有“不同的规则”（你的问题“不应该只有一条正确的吗”）

6 方程/Kapila 模型的相能量方程是非守恒的。穿过激波时守恒律只定混合物的 Hugoniot，耗散在两相之间怎么分无粘模型不定；数值上由格式的粘性路径决定（路径守恒格式的老问题，Abgrall–Karni 2010）。能量亏损 $\delta$ 的分配 $\Lambda_k$ 是本格式里唯一的调节手段，所以“规则”实际上是在选格式收敛到哪一组激波关系。模型自己的激波关系是 SPB (II.5)（Saurel et al. 2007，每相沿自己的 Hugoniot、共用混合压力；epoxy–spinel 实验验证；`tests/exact5.py` 用它）。正确的规则只有一条：让极限激波满足 (II.5) 的那条。之前的质量分配（V10）是从格式的公共数值运动粘性推出来的（粘性加热 $\propto m_k$），描述的是格式而不是模型；V15 的 $E_k$ 规则只管 $\delta<0$ 的保正。

### 16.2 剖面分析（B5.2 (b)，`scratchpad/profile.py`）

激波系下的定常剖面：Rayleigh 线 $P(v)=p_0+j^2(v_0-v)$，混合物 $\mathrm de=-P\,\mathrm dv$（自动落在 Hugoniot 上，与分配无关），相 $k$ 的 $\mathrm de_k=-p\,\mathrm dv_k+\mathrm dq_k$，$Y_k\mathrm dq_k=\lambda_k(p-P)\mathrm dv$。(II.5) $\Leftrightarrow$ $Y_kq_k=\int(p-\bar p)\mathrm dv_k$。

- 弱激波：$Y_kq_k\rho=\alpha_k\mathcal G_k\Delta p^3/(6K_k^2)$（单相熵产 $T_k\Delta s_k$，路径无关）$\Rightarrow$ 唯一的局部规则 $\lambda_k\propto\alpha_k\mathcal G_k/K_k^2$。
- 强激波：用常数份额 $c$ 积分剖面 ODE，解使终态满足 (II.5) 的 $c$；它被终压处的 Hugoniot–等熵能隙 $Q_k=m_k(v_k^{\rm pre}-b_k)f_k(p_0\to p_1)$ (B5.5) 逼近（表见 B5.2），而冻结在 $p_0$ 的弱规则、$T_k\Delta s_k$ 形式、体积份额 $\alpha_k/K_k$ 都不行。
- 各规则在同一激波速度下的终态 $p_1$ 偏差：质量分配 epoxy–spinel $10^{10}$ Pa $+7.0\%$、$2\times10^{11}$ $+9.8\%$，水–空气（0.5）$10^6$ 已 $+9.9\%$；SPB 重初始化 $\alpha_k/(\gamma_k-1)$ 与质量相近；局部弱规则 $p_1\le10^9$ 时 $10^{-8}$–$10^{-3}$，微量气体强激波 $+6\%$、气体温度高 50 倍。
- 这解释了一直没追的 SPB 5.2 偏差：V15 的激波后密度 3966 对精确 3766.7（$+5.3\%$），$L_1(u)$ 118。

### 16.4 规则（B5.2 (c)–(e)，`defect_split`、`shock_budget`、`phys_dissipation`）

$$\Lambda_k(\delta)=\min(\delta,Q)\,\lambda^{\rm II.5}_k+(\delta-\min(\delta,Q))\,\lambda^E_k\ (\delta\ge0),\qquad \delta\,\lambda^E_k\ (\delta<0),$$

$\lambda^{\rm II.5}_k=Q_k/Q$ 由 $\pm2$ 格模板上 $X^*$ 混合压力的极值、压力最低格的波前比容与本格的质量算出（只在压缩格），$\lambda^E_k=E_k/\sum E$。一次激波通过一格的亏损之和恰为 $Q$，所以预算在激波处不起作用，在光滑区（$Q\propto\Delta p^3$）把全部亏损判为误差。$\Lambda_k$ 对 $\delta$ 连续，分段按 $\delta(p^{\rm guess})=D_0+p^{\rm guess}s$ 取：$G(P)$ 连续，V15 的分支冻结与 active-set 校正去掉（它解决的是按 $D_0$ 而不是 $\delta$ 分支造成的不连续）。两相等熵涡 $64^2$：Newton 2.0 次/级、$\max|G|$ $6\times10^{-16}$（V15 2.99 次、10503 次翻转），$L_2$ 不变（$p$ 0.4814 对 0.4813）。显式程序用同一规则（`RelaxationSubsystem` 先算模板预算）。MG 相：Hugoniot 与等熵线 $(p-p_r)v^{\Gamma+1}=$ 常数二分求根，$E_k$ 取冷曲线之上的热能。

### 16.8 空化 RM 在 $t=0.73$ ms 停住：闭合的逐相单调性条件过严

V16 第一版重跑二维时空化 RM（算例 71）在 $t=7.30\times10^{-4}$ s 处步长一路减半到 $10^{-11}$（2 小时没到第一个快照；V15 整个算例 570 s）。出问题的格是激波刚扫过的水格（$\alpha_{\rm gas}=3\times10^{-8}$，$s=7.7\times10^{-4}$）：$D_0=(\rho e)^C-\sum\varepsilon^{\rm tr}\approx-3.06\times10^5$，$ps\approx+3.06\times10^5$，$\delta=D_0+ps$ 在解附近过零，落在 $0\le\delta<Q$ 段，微量气体按 (II.5) 分到 $\lambda_{\rm gas}\approx1$。该段 $\Lambda_k=\lambda_k(D_0+ps)$，气相的 $N_k=E_k+\lambda_kD_0\approx15-3\times10^5<0$：$\alpha_{\rm gas}(p)$ 随 $p$ 增，旧闭合在求根前逐相要求 $N_k>0$，直接判为无解。

- **第一次修改（舍弃）：** 把 $\Lambda_k$ 在全局迭代值 $p^{\rm guess}$ 处取成常数（$B_k=\alpha^{\rm tr}_k$）。收敛处方程相同、RM 通过、一维逐位或第 4 位相同，但 $G(P)$ 多了经 $p^{\rm guess}$ 的依赖，闭合内能量只在收敛时一致：Gresho $M=10^{-5}$ 的 Newton 停在 $10^{-10}$，1836 次拒绝。
- **最终修改：** 逐相单调不是必要条件。$\Phi(p)=\sum_k\alpha_k(p)-1$ 由液体主导（液体斜率 $\sim-1/K_{\rm water}\approx-2\times10^{-10}$/Pa，气体 $\sim+5\times10^{-13}$/Pa），仍递减。所以 $p$ 闭合在**每个试探 $p$ 处**按 $\delta(p)$ 选段（$\Lambda_k(\delta(p))$ 精确、分段仿射、连续，闭合内 $\sum\varepsilon_k=(\rho e)^C$ 对任意 $p$ 成立），去掉逐相 $N_k>0$ 的预检，只要求 $\Phi$ 有带区间的根、解处各相可容许（`closure_p`）。Gresho $M=10^{-5}$、$10^{-6}$：0 次拒绝（1.00、1.02 次 Newton/级）；空化 RM 越过 $0.73$ ms、0 次拒绝；SPB 4.3.2 拒绝 4 → 3。
- 有限 $\mu$ 的两压力闭合、有限 $\theta$、MG 闭合仍按 $\delta(p^{\rm guess})$ 选段（收敛时相同）。
