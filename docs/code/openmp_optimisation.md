# SPB6_PC_IMEX 的计算效率优化（OpenMP 版）

文件：`src/SPB6_PC_IMEX_omp.cpp` + `src/spb6_physics_omp.h`。原来的 `SPB6_PC_IMEX.cpp`、`spb6_physics.h`（显式程序与其他 IMEX 变体共用）
与 `bin_SPB6_PC_IMEX` 都不变。格式、闭合与所有判据都不变；改的只是求根的迭代路径、内存分配与并行。

```
g++ -O2 -std=c++17 -fopenmp -I/usr/include/eigen3 src/SPB6_PC_IMEX_omp.cpp -o spb6_imex_omp
OMP_NUM_THREADS=4 ./spb6_imex_omp case=70 ...     # 命令行与原程序相同；另有可选的 jreuse=1（4.3 节）
```

## 1. 热点（原程序，gprof + 分阶段计时）

| 阶段 | 一维 SPB 4.3.1（case 5） | 二维氦泡（case 70，300×80） | JWL-水（case 61） |
|---|---|---|---|
| p 闭合 `closure_p`（含 `p_coef`、`defect_split`） | ~80 % | ~45 % | — |
| MG 闭合 `closure_p_mg` / `alpha_mg` | — | — | ~85 % |
| 激波剖面积分 `prof_integrate`（激波预算） | 1 % | 5–30 % | 5 % |
| 每级分配与清零（`StageData` 等，mmap 缺页） | ~20 %（4 线程时） | 5 % | 9 % |
| 显式部分（重构、Rusanov） | 串行 | 串行 | 串行 |

根源：

1. **p 闭合的 Newton 没用上初猜。** 区间从初猜向外扩张后，初猜恰好是区间的端点；原代码只在初猜严格位于区间内部时才从它起步，
   否则从区间中点起步。Phi 凸且递减，从右侧起步的 Newton 步跳出区间，被换成二分，约 12 次二分才回到根附近：
   每次闭合约 15 次 Phi + 15 次 Phi'，而全局 Newton 给的初猜通常离根只有一个舍入或一个小步。
2. **每次求 Phi 都重算与 p 无关的量。** `p_coef` → `defect_split` → `E_above` 在每个试探 p 处都算一遍。
3. **MG 闭合同样的问题，而且更严重。** `alpha_mg` 的初猜就是根（舍入内）时，Newton 修正小于一个 ulp，`an == lo`，
   被判为“出界”换成几何二分，再用约 30 次迭代爬回来：每次约 20 次 `mg_ref`（两个 `exp`）。外层 `closure_p_mg` 有同样的判断次序。
4. **激波份额的 Illinois 迭代从 [−40, 40]（logit 坐标）开始**，每次迭代是一次完整的 RK45 剖面积分：每个强激波格 20–45 次积分；
   而且并行循环是 `schedule(static)`，激波格集中在少数线程上。
5. **每级重新分配约 60 个 double/格的工作数组。** glibc 对 > 128 KB 的块用 mmap，每级都缺页、清零、再 munmap。
6. **串行部分**：显式重构与更新、`caldt`、级数据准备（单位体积内容、声速、残量尺度、面系数、闭合类型）、RK 级组合、Newton 的标量循环。
   一维时 y 向的 4 个虚行也被完整重构与准备（结果从不被读取），工作量是需要的 5 倍。

## 2. 改动

### 2.1 求根（`spb6_physics_omp.h`）

| 位置 | 改动 | 每次闭合的函数求值 |
|---|---|---|
| `closure_p` | 与 p 无关的量（D0、lam^E、预算 Q、A_k、B_k 中不含 lam 的部分）每次闭合算一次；Phi 与 Phi' 一起算；带区间的安全 Newton 从初猜出发（上界未知时向上 4 倍扩张，与原来一样）；先判 Newton 步是否已在舍入内，再判出界 | 约 30 → 2.9 |
| `alpha_mg` | 初猜在闭区间上就从它起步；先判 Newton 步 | `mg_ref` 20 → 4.8 |
| `closure_p_mg` 外层 | 先判 Newton 步 | — |
| `shock_share` | Illinois 的初始区间以弱激波份额（定理 8）的 logit 为中心 ±1，不变号则倍增扩张，最远到原来的 ±40；迭代与收敛判据不变 | 剖面积分 21–44 → 6–9 |

Phi(p) 的算术次序与原来的 `p_coef + alpha_p` 逐位相同：同一个 p 给出同一个 Phi。只有迭代停在哪个 p 不同，根的差别在收敛判据
`|Δp| ≤ 2e-16 (|p| + |p_lo|)` 之内。激波份额的根在原来的容差（logit 坐标 1e-10）内相同。

### 2.2 内存

- `mallopt(M_MMAP_THRESHOLD / M_TRIM_THRESHOLD)`：大块留在堆里，不再每级缺页。
- `StageData`、Newton 与 BiCGStab 的工作向量、`Pold`、`cz`、RK 的级张量 `Hs` 与级态 `Ust`：分配一次，各级复用（只在网格尺寸变化时重建）。
  每级都会整体重写的量不清零；只在 CL_MU 格写的阻抗 Z0、Z1 每级重置为 1。

### 2.3 OpenMP

所有新加的并行循环都是逐格或逐面独立的写，或者是 max / && 归约（与次序无关）。内积仍用固定大小的块求和，块的次序固定。
所以**结果与线程数无关、逐位可重复**（1、3、4 线程逐位相同，已验证）。

| 函数 | 并行化的循环 |
|---|---|
| `Update` | 速度上界（max 归约）、面速度、Rusanov 更新 |
| `TVDReconstruction` | 舍入尺度、逐格限制与面值（facediag=1 时串行） |
| `caldt` | max 归约 |
| `PressureSubsystem` | 单位体积内容、增量供体、冻结声速、残量尺度、Pold、x/y 面系数、闭合类型；激波预算改为 `schedule(dynamic, 8)` |
| `Newton_Solver` | 尺度 s_q、残量范数（max）、步长判据（max）、P 更新、Thomas 前的三对角抽取、舍入底检查 |
| `GMRES_Solver`（BiCGStab） | Jacobi 对角、初始残量、最后的 x 更新；块求和的块大小 4096 → 1024（n = 4000–100000 时内积才分得到全部线程） |
| `main` | RK 级组合与级导数 Hs |

另外两处只减少工作量、不改结果（与改前逐位相同，已验证）：

- 一维时只重构、只准备内部那一行（y 向虚行的结果从不被读取）。
- RK 级组合只算内部格：虚格紧接着被 `bound_cond_u` 整体重写。

### 2.4 编译选项

`-O3`、`-O3 -march=native` 与 `-O2` 的差别在测量噪声内（±10 %）；`-march=native` 会用 FMA，结果随机器变。保留 `-O2`。

## 3. 验证

判据：优化版与原程序之差，不大于原程序自身在舍入量级扰动下的变化（差分 Jacobian 步长 1e-7 → 1.01e-7，Newton 的解在容差内不变）。
二维激波—界面问题本身把舍入放大到 1e-3（平均）/1e-2（最大）量级，所以逐位相同不是可行的判据。

## 4. 用法与选项

- 命令行与原程序完全相同；输出格式相同。
- `OMP_NUM_THREADS` 取物理核数。结果与线程数无关（逐位相同），可以用不同线程数续算或比较。
- **jreuse=1**（默认 0）：同一级内复用上一次的差分 Jacobian。只在级的第一次迭代、上一步收缩率 > 0.25、上一步用了线搜索阻尼、
  或复用的 Jacobian 使线搜索失败时重建。Newton 次数变多（case 72：3.0 → 5.6 次/级），但 Jacobian 次数变少，总时间再省 13–25 %，
  精度同样在噪声内。收敛判据不变，所以是安全的；默认关闭只是为了与原程序的迭代路径一致。
- 没做、也不建议做的：`-ffast-math`（代码依赖 NaN/inf 判断）；`-march=native`（FMA 改变舍入，结果随机器变，速度无明显差别）；
  解析 Jacobian（闭合的求根现在只要约 3 次函数求值，差分 Jacobian 的主要代价已经是残量组装本身）。
