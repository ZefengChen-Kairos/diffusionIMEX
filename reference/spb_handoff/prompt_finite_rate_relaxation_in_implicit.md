# 任务 Prompt：把有限速率松弛放进 6+1 IMEX 的隐式压力解

## 0. 背景（先读，不要跳）

我是 Kairos（Cambridge LSC 博士生）。我在做 Saurel–Petitpas–Berry 2009（JCP 228, 1678）6+1 方程松弛模型的一维 IMEX 格式，代码是 `/home/claude/spb/spb_imex.cpp`（当前 v23，备份按 `spb_imex_vNN.cpp` 命名，改动前先备份成 v24）。推导文档是 `/mnt/user-data/outputs/spb_6plus1_imex_derivation_v3_2026-10-07.md`。

**现有算法（默认开关）：**
- 状态 Q = (α₁, m₁, m₂, ρu, ε₁, ε₂, E)，ε_k = α_kρ_k(e_k − q_k) 为热内能，E 含 Σm_kq_k。
- 时间：IMEX-RK(2,2,2)，γ = 1 − 1/√2；Δt 由物质 CFL（max|u|）定。
- 显式：所有量按 Q·u 做 Rusanov（s = max|u|），`AVOL=1` 时 α_k 按体积输运，Σα_k^x = 1 − (Δt/Δx)d(ū^e)。
- 隐式：每格一个未知量 p_i；u_f = ū*_f − (Δt/Δx)(p_{i+1} − p_i)·2/(ρ_i + ρ_{i+1})；增量 du_f = u_f − ū^e_f（`UREF=1`），m_k、α_k、ε_k 加增量通量 −(Δt/Δx)d(X_f du_f)，面值取供体格（`DONOR=1`）。
- 闭合（`Gth`、`eval`、`Gloc`）：
  - 力学：α_k(p) = (γ_k − 1)(ε_k^tr + pα_k^tr) / (γ_k(p + π_k))，G_i = Σα_k − 1；
  - pT/pTg 激活格：G = ρe⁰ − ρe_eq(ρ, p, Y)，其中 ρe⁰ = Σε_k^tr + p(Σα_k^tr − 1) + Σm_kq_k。
- 求解：Gauss–Seidel 带区间预扫 + Newton（三对角 Jacobian，Thomas 解，回缩保可容许）。
- 级末：`relax_reinit`（SPB 3.3 + 3.4），然后 `thermo_relax`（Pelanti–Shyue 2014 的 pT、pTg 投影，激活判据为 ε_I ≤ α₁ ≤ 1 − ε_I，且 pTg 只在 T > T_sat(p) 时做）。

**核心创新点：** 松弛在隐式压力解的内部完成，所以隐式算子带的是平衡（Wood/HEM）刚度，而不是冻结刚度。

**本任务：** 把这一点从无限速率推广到有限速率，使同一个隐式解在冻结极限（速率 → 0）和平衡极限（速率 → ∞）之间连续过渡，并且在刚性松弛极限下渐近保持（AP）。

- Pelanti 2022, IJMF 153, 104097（`971563d7-...pdf`）：任意速率热/化学松弛（指数解），测试 8.2.1 的 p / pT(f) / pT / pTg(f) / pTg 五档。

- Schropff, Petitpas & Daniel 2026, JCP 547, 114545（`074a07b0-...pdf`）：6 方程 TV 分裂半隐式，两个相压力隐式求解，压力松弛在 IMEX 之后单独做（冻结刚度）。这是直接的对比对象。

## 3. 阶段 1：有限速率化学松弛 ν（p、T 瞬时，Y 有限速率）

**模型：** 源项按 Pelanti 2022 的定义。传质 ṁ = ν(g_l − g_v)，正值表示液相变成汽相；ν 的单位和取值按论文原文。激活判据也按论文对应算例的写法（例如只在 T > T_sat 时开启），不要自己发明。

**离散（在隐式级里做后向 Euler，等价于把源项放进 IMEX-RK 的隐式部分）：**
对给定的 p（Newton 的未知量），每格解一个内层标量方程求 Y_v：

  R(Y_v; p) = Y_v − Y_v^tr − (a_ii Δt · ν/ρ)·[g_l − g_v](p, T(ρ, p, Y_v)) = 0

其中 T(ρ, p, Y) 由 v = ΣY_k v_k(p, T) 确定（就是现有 pT 闭合里的 T）。然后：

  G(p) = ρe⁰(p) − ρe_pT(ρ, p, Y_v(p))，其中 m_k = ρY_k

- **先推导，再验证以下性质（写进文档）：**
  - ν = 0 时退化为现有 cl = 1（pT），ν → ∞ 时退化为现有 cl = 2（pTg）；
  - R 对 Y_v 是否单调，内层根是否存在且唯一（在 (0, 1) 上用区间求解）；
  - G 对 p 是否仍然单调，预扫的区间是否仍然有效；
  - Jacobian 怎么取：dY_v/dp 由隐函数定理得到，或者整格残量对三个压力做差分（与现有做法一致）。
- **级末：** `thermo_relax` 里对应的 pTg 投影在 ν 有限时必须关掉，否则会覆盖掉有限速率的结果。pT 投影保留（T 仍然是瞬时平衡）。
- **时间积分：** 确认 IMEX-RK(2,2,2) 的隐式表是 stiffly accurate 且 L 稳定（ARS 型），这样 ν → ∞ 的极限才是 AP 的。级导数 Hs 必须包含源项的贡献。如果现有结构（源项在级末投影）和这个要求冲突，先在文档里写清楚冲突在哪里，再改。
- **验证：**
  - **0D 测试：** 周期域，u = 0，均匀亚稳液体加少量汽相。输运为零，只剩松弛。和高精度常微分方程解（scipy `solve_ivp`，Radau，rtol 1e-12）对比时间收敛阶，期望 IMEX-RK 二阶。另外取 Δt ≫ τ 的情形，确认结果直接落在平衡态且不振荡。
  - **8.2.1：** 复现 Pelanti 2022 Fig.4 的 pTg(f) 曲线。EOS 和参数按论文原文。如果论文用的是 NASG 而代码只有 SG，先停下来告诉我，不要拿 SG 的结果去对 NASG 的图。
  - **单调性：** 中心压力要满足 pT ≤ pTg(f) ≤ pTg。

## 4. 阶段 2：有限速率热松弛 θ（p 瞬时，T 有限速率，ν = 0）

**模型：** 按 Pelanti 2022 的定义，Q = θ(T_v − T_l) 是流入液相的热流（单位体积单位时间的能量）。

**离散：** 给定 p，力学闭合加上传热量 ΔQ = a_ii Δt θ (T_v − T_l)^{n+1}：

  α_k [ (p + γ_kπ_k)/(γ_k − 1) + p ] = ε_k^tr + p α_k^tr ± ΔQ（液相取 +，汽相取 −）

SG 下 T_k = (p + π_k)α_k / ((γ_k − 1)c_{v,k}m_k)。可以看出，在给定 p 时 α_k 对 ΔQ 是线性的，T_k 也对 ΔQ 线性，所以 ΔQ 有**闭式解**。然后 G = Σα_k − 1。

- **先推导，再验证：**
  - θ = 0 时退化为力学闭合；θ → ∞ 时 T_l = T_v，退化为 pT 闭合（cl = 1）；
  - G 对 p 的单调性是否保持；
  - Jacobian 的解析形式。
- **级末：** θ 有限时关掉 pT 投影。
- **验证：** 0D 收敛阶测试，加上 8.2.1 的 pT(f) 曲线（参数按论文）。
- **范围：** θ 和 ν 同时有限的组合不在这次范围内。Pelanti 也要求有限 ν 时 pT 先瞬时平衡；另外两者同时有限需要界面能量闭合，Sirianni & Re 用的是 e_I。

## 5. 阶段 3（可选，先只写推导，不写代码）：有限速率压力松弛 μ

每格两个未知量 (p₁, p₂)：
- α₁^{n+1} = α₁^tr + a_ii Δt μ(p₁ − p₂)^{n+1}
- 相能量里的压力功用各自的 p_k，松弛功用 −p_I Δα
- 动量方程用 p = Σα_k p_k
- Jacobian 是 2×2 块三对角

**目标：** μ = 0 时与 Schropff 的冻结方案一致，μ → ∞ 时与当前方案一致。
