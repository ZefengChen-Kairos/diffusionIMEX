**编译：** `g++ -O2 -std=c++17 spb_imex.cpp -o spb`

**运行：** `CASE=k [开关=值 ...] ./spb MODE N CFL out.dat [预扫遍数] [阶数]`

**回归：** 在包的根目录先编译出 `./spb`，然后执行：

```
bash scripts/suite.sh TAG && python3 scripts/suite.py TAG
```

结果写到 `./run/su/`。可以用环境变量 `RUN`、`REF`、`SPB` 改路径。整套约 2 分钟。

## 3. 默认开关（它们的含义）

- `AVOL=1`：α 按体积输运。这等价于线性路径的 path-conservative 涨落，ū 取面速度，差 O((rΔu)²)。
  - **注意：** 文件头注释写的“path-conservative Rusanov”是旧选项 `AVOL=0` 的说法。
- `EXPLE=1`：相内能的对流放在显式部分。
- `UREF=1`：增量的参考速度取显式通量的面速度。这是二阶的必要条件；`UREF=2` 在时间上只有一阶。
  - **注意：** 代码注释里还写着“UREF = 2 (默认)”，这是过时的，以变量的实际值为准。
- `DONOR=1`：增量通量的面值按增量方向取供体格。
- `SLOC=0`：Rusanov 耗散速度取全局 max|u|。
- `PFACE=0`：面压力取算术平均。
- `RELAX`：0 只做力学松弛，1 加热松弛，2 加化学松弛，3 是 p-pTg。
- `EPSI`：热/化学松弛只在 ε_I ≤ α ≤ 1 − ε_I 的格子里打开。
- `RAMP`：从静止起算的算例，首步用声学步长，之后每步最多放大 1.2 倍。
- 默认关闭：`FLAT=0`（激波处隐式耗散）、`FLATA`、`K1`、`FSC`。

**输出列（10 列）：** x, p, u, ρ, α_g, Y_g, ρ₁, ρ₂, c_frozen, c_wood

**套件里的计数：**
- `fb`：二阶 RK 退回一阶（RK1 fallback）的次数；
- `nf`：Newton 未收敛的次数；
- `pf`：压力触底被托住的次数。

`fb` 和 `pf` 不为零，说明有局部的保护机制在起作用。论文里要么去掉它们，要么如实报告。

## 5. 已知缺陷（未解决）

1. **水–气 4.3.1：** 气侧速度过冲（614 vs 492），激波位置 0.978 vs 0.935。根源是界面起步：开头几步显式部分把 α 抹进混合格，两相带着各自的压力进去，随后瞬时松弛是不可逆的，熵进入气相，变成接触间断上的“化石”误差。加密网格不能消除。
2. **十二烷稀疏波尾部下冲：** [0.1, 0.4] 上的最小压力明显低于参考解。真二阶以后变得更明显。
3. **激波附近振荡：** FLAT 可以缓解，但 κ₁ 还没定下来。κ₁ = 0.1 时 5.2 的过冲 1.017；κ₁ = 0.03 时 5.1 的过冲 1.085。
4. **5.2 波后状态：** ρ ≈ 3930，5 方程精确解 3767；开 FLAT 后为 3828。这是非守恒积离散带来的分相加热分配问题，path-conservative 本身也不能保证修正。
5. **SPB Fig.2（4.5）中心压力：** 显式在 N = 500/1000/2000 时依次为 47.7e3 / 30.0e3 / 18.1e3，外推到 N = 5000 约 9.6e3，与论文的 1e4 一致。IMEX 约 380 Pa，精确解 664 Pa。

## 6. 已证伪、不要重试的路线

| 路线 | 结论 |
|---|---|
| `UREF=2` | 时间上只有一阶，已改为 `UREF=1` |
| `SLOC=1`（面局部耗散速度） | 空化中心塌陷（约 ±500 的 pT 停滞） |
| `FLATA=1`（FLAT 面上取 α 平均） | 改善水–气只是因为跨界面的非物理能量转移，还会导致 Newton 失败；取 min α 是干净的做法 |
| 用 pmin 判断 DONOR 的好坏 | 用错了指标，应该用对精确解的 L1 |
| 把 Fig.2 的 Y_v 肩部归因于二阶重构 bug | 实际是亚格子尺度的起步物质（N = 1000 时约 0.14 格） |
| 扫描 ε_I 来消除气泡算例的过早闪蒸 | 无效。原因是初始条件本身处于亚稳态 |
| pTg 闭合在临界点 PCRIT 处不连续 | 曾导致 Newton 失败，已用端点连续延拓修复（推导文档 §11.2–11.3） |
