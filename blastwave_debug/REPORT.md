# Blast wave 调试报告：论文二（双参数 ε-IMEX）与 `Final_emb_omp.cpp`

日期：2026-11-03。对象：
- 论文一 `2608.15837v11`（三分裂 IMEX，二阶，LSDIRK2，嵌套 Newton 保正）与其代码 `NEWCTIMEX.cpp`；
- 论文二 `IMEX_MHD.pdf`（双参数 ε_M/ε_B 自适应分裂，三阶，SA-DIRK(3,4,3)，HLLEM + 特征 WENO3-Z，CT 嵌入压力算子）与其代码 `Final_emb_omp.cpp`。

所有图、脚本、补丁都在仓库目录 `blastwave_debug/` 下（文末有清单）。所有数值实验在 128² 与 256² 上做（1000² 一次要几小时，本机 4 核跑不动），结论对 1000² 的适用性在第 7 节讨论。

## 1. 结论（先看这里）

1. **论文二 blast wave “结果差”的具体表现**：激波位置、密度/压力/磁压的峰值和平台都与独立参考解一致（比论文一的二阶代码更准），问题全部在 blast **内部**（|x| < 0.1，|y| < 0.15）：t ≳ 0.007 以后出现网格尺度的 div u 条纹和 v_y 毛刺，周期 6–9 格，**随分辨率加密变得更严重**（128² 时内部 div u 谱中周期 ≤ 8 格的能量占 8%，256² 占 41%；参考解 ≤ 1%）。这是数值伪解，不是物理结构。
2. **直接原因**：内部区域 M ≈ 0.2、M_A ≈ 0.2（都在切换带 [0.15, 0.4] 内），ε_M、ε_B 中位数只有 0.05–0.08，压力通量和磁通量几乎全部走隐式路径；隐式路径是四阶中心有限体积算子，除了 χ 门控的磁 Laplacian 外没有任何激波耗散（论文一压力方程的激波激活 Laplacian (45)/(85) 在论文二里被去掉了；`Final_emb_omp.cpp` 里 `Pressure_Subsystem_AX_ref` 还算着 `lap_p`，但**从未加到 Ax 上**，是死代码）。而 blast 内部并不是真正的低马赫光滑流：从 ±x 反射回来的激波在中心汇聚，δp/p ~ 0.1–0.4，β ≈ 1.4。显式部分（HLLEM-WENO3）本身是干净的：把 ε 固定为 1（全显式，E1/E12）内部与参考解一样光滑；ε 固定为 0（全隐式，E5）最差。
3. **修复 A（已实现、已验证）**：把论文一的压力激波 Laplacian 按 (1−ε_M) 面权重加回隐式压力算子（二阶 M-矩阵算子、四阶算子、预条件模板三处都加，M-矩阵性质与保正定理不变）。128²：内部网格尺度能量 8% → 1%，v_y 粗糙度 0.74 → 0.45（参考解 0.21–0.25）；256²：41% → 8%，粗糙度 1.09 → 0.98。条纹基本消失，但 256² 上膨胀区（χ = 0）残余毛刺仍在。
4. **修复 B（已实现、已在 128² 和 256² 验证，见第 6 节）**：切换函数除了马赫数还看局部压力/磁压的相对变化，M_eff = max(M, √(max|Δp|/p))、M_A,eff = max(M_A, √(max|Δm|/m))。这正是论文二结论里自己提出的方向（“ε 和激波指示器都由速度驱动，对静止流体中的压力跳变是盲的”）：它让内部的反射激波走显式 HLLEM，而对真正的低马赫光滑流（δp/p ~ M²）不起作用，AP 性质不变。A + B 把内部 v_y 粗糙度降到 0.27（128²）/0.38（256²）（全显式 0.26/0.27，参考解 0.21–0.24），时间步只缩小 6–8%，激波位置和极值不变；256² 上残余一点交界处的毛刺（第 6 节）。**按作者决定，B 不采用**（切换函数保持论文二的形式）；补丁里 `pswitch` 默认 0，只作对照。不采用 B 时内部“边框”（|y| ≈ 0.08–0.13）的毛刺保留，其余振荡由 A + C 解决（第 6.2 节）。修复 A 在光滑区逐位为零、不影响三阶（第 6.2 节的涡收敛表）。
4b. **密度/压力的振荡有两处**（第 6.1 节）：内部的 ρ “十字亮点”和 p 网格纹路是上面同一个隐式路径问题，A + B 后消失；快激波后面的翼区环带（β ≈ 0.01、M ≈ 2.4、M_A ≈ 0.26、ε_M = 1）里 ρ 的径向条纹/棋盘格是 HLLEM 线性退化波反耗散在强激波后的奇偶解耦（Quirk 型），A、B 对它无效；**修复 C**（δ_k 乘以激波压平因子 (1 − χ_face)，χ_face 含压力跳传感器，再加上限 δ_k ≤ 0.75）把环带 ρ 粗糙度 128² 从 1.62 降到 0.50（参考解 0.32–0.45）、256² 从 2.51 降到 0.70（参考解 0.31–0.56）；三个修复合用后 ρ、p、v_y 在 128² 上与参考解一样光滑，256² 上内部一致、环带还剩少量条纹，斜激波层里 p 的锯齿是另一个次要问题（第 6.1 节末）。
4c. **远场压力塌陷**（第 6.4 节，作者反馈「log p 太小」后查出）：快激波**前方**的环境区压力从 0.1 掉到 0.006–0.008（全场 30% 的格子低于环境值），把 log₁₀ p 的色标底端从 −1.0 拉到 −2.1。**p_max 是正常的**（256² 为 211.7–213.7，参考解 1024² 为 225.5）。原因是 β = 5.13×10⁻⁴ 下热能只占总能的 0.128%，而激波脚处 CT 重构的 B 比守恒通量抬升 E 的位置提前了不到一个网格：|B| 失配 0.056% ⇒ 压力误差 −93%。**不是**修复 A/C、**不是**累积漂移（探针显示第 280 步前压力精确为 0.1，塌陷发生在前沿经过的 2–3 步内）、**不是**嵌入式 CT 丢掉的 Newton 余项（实测只占亏损的 1%）、**不是** Picard 截断。论文一的代码同一缺陷更严重（远场**负压** −0.005，半个域低于环境值，所以它的 log p 图必然做了裁剪）。**修复 D**（最小等离子体 β 地板，`betafloor=5e-4`）把 log₁₀ p_min 从 −2.15 恢复到 −1.01（参考解 −1.01），p_max 不变、激波剖面变化 < 2%、稳定性不变；它是保正限制器不是根治，默认关闭。
5. **论文与代码的参数不一致**（两篇论文都有）：代码的 blast wave 用 B₀ = 70/√(4π)、γ = 1.4、erf 平滑的初值、CFL = 0.1；论文文本写的是 B₀ = 100/√(4π)、γ = 5/3（论文二“除非另有说明”）、尖锐初值、CFL = 0.8。论文一图 13 的磁压色标（环境 m ≈ 195 = 70²/8π，而不是 100²/8π ≈ 398）和 |u|² 最大值 240 说明论文一的图也是用 B₀ = 70 算的。论文二 κ₁ = 0.4，代码 `shock_kappa1 = 0.05`（论文一 κ₁ = 10⁻³，代码一 0.001，一致）。
6. CFL 0.1 与 0.4 在 128² 上结果逐点几乎相同，CFL 不是问题；blast wave 的时间步本来就等于全显式磁声步长（dt/dt_MHD 中位数 1.06–1.09，因为激波区 ε = 1 且内部快磁声速 ≈ 40 与激波区一样大）。

## 2. 两个算法与两份代码的对应（核对结果）

### 2.1 论文一 ↔ `NEWCTIMEX.cpp`

- 三分裂 F = F^c + F^p + F^B，对流显式（`RusanovC_Update`，s_max 取**全场** a_max：第一步用磁声速，之后用物质速度最大值），磁子系统隐式（`MagSubsystem_UpdateB` + `Magnetic_Subsystem_AX`，GLF Laplacian，κ = |λ^B|_max Δx，不用 χ 门控，与论文 (82)-(83) 一致），磁通量更新 `Pressure_flux_Update`，压力两次求解（`PreSubsystem_Pressure`，`all_correction`），能量按定义重组（`DefinitionofU`，论文 (91)），CT（`Unstaggered_CT_Consistent`：面 EMF = 隐式磁通量的对偶，GS05 角点组装，B = curl A 二阶中心）。
- 压力算子 `Pressure_Subsystem_AX`：V'(p)·p − Δt²·div(h ∇p)（紧致五点 M-矩阵）− V'·Δt·div(χ|u|_max Δx ∇p)（**激波激活的压力 Laplacian，论文 (45)/(85)**，`add_pvisc = MaterialSpeedp`，`GLF`，κ₁ = 10⁻³）。嵌套 Newton + Cor.1 自适应 Mbig。
- 代码一与论文一一致。blast wave 初值是 B₀ = 70/√(4π)、γ = 1.4、erf 平滑（宽度 √(Δx²+Δy²)），与论文 (106)-(107) 的 100/√(4π)、尖锐初值不符。

## 6.3 两篇论文里的数学问题（核对清单）

我逐条核对了两篇论文的推导：分裂系统的 Alfvén 2×2 块 (20)-(22)、磁声四次方程 (23)-(28)、右特征向量 (37)-(38)、熵波精确左特征向量 (36)、定理 2.1 的对称化证明、引理 2.3、MP3 的命题 3.1、HLLEM 的 (51)-(59)、四阶有限体积算子 (89)-(92)、SA-DIRK(3,4,3) 表 (88) 的三阶条件、论文一的定理 1 / 推论 1 / 定理 2 / 命题 3——这些都对（四次方程的实根性我另外用 2×10⁵ 个随机状态数值核了一遍，`hyperbolicity_check.py`，没有复根；(88) 的系数满足全部三阶条件）。有问题的是下面几处（`jordan_check.py` / `jordan_check.txt` 是精确有理数的 Jordan 结构计算）：

1. **论文一 2.3 节，对流子系统**：“one eigenvector associated with λ^c = 0 is missing”——错，缺的是 λ^c = u 的特征向量（(ρ, u) 的 Jordan 块，即无压气体动力学的退化）：λ = u 代数重数 4、几何重数 3；λ = 0 的四个特征向量都在。论文二第 4 页写的是 λ^c = u，是对的，论文一要改成一致。
2. **论文一 2.3 节，磁子系统**：“associated with λ^B = 0 there are two eigenvectors missing, so the magnetic sub-system is weakly hyperbolic”——错。去掉 B_x 列（用 ∂_x B_x = 0，论文二定理 2.1 就是这样做的）后磁子系统是**强双曲**的：λ = 0 代数重数 3、几何重数 3（e_ρ、e_p 和沿磁场的流动 (0, 1, B_y/B_x, B_z/B_x, 0, 0, 0)）；保留 B_x 列的 8×8 形式也只缺**一个**（散度模），不是两个。这句话在论文一里只是动机性的叙述，不影响格式，但要改。
3. **论文二 (59) 之后**：“δ_k → 0 when the corresponding speed approaches the envelope, as it does near strong shocks”——后半句不成立。强激波处包络 [s_L, s_R] 由快磁声速张开，线性退化波速 ũ 在中间，δ_C = 1 − ũ⁻/s_L − ũ⁺/s_R = O(1)；δ_k 只在包络塌缩到物质速度（ε → 0 或单侧超声速）时才趋于零。这正是翼区环带 ρ、p 奇偶解耦的机理（第 6.1 节，修复 C 补的就是这一项），不是笔误而是方法里缺的一块。
4. **论文二 3.4.4 节的保正陈述**：(a) 定理用的是论文一的引理 1（T 零行和、非正非对角）；代码里的 T₂ 还含 −h²div[(1−ε)H p_f ∂_n ε]（上风面压力）这一项，它不是零行和。结论仍成立，只是 (52)/(55) 里的 M 要换成 M + r_i（r_i 是行和，|r_i| ≪ M），论文应说明。(b) 定理保证的是**求解出的** p；存储的总能用线性化的 k、m（(81)/(100)）装配，存储状态的压力 p_true = p_solved − (γ−1)(½|m − m_E|²/ρ + ½|B − B_E|² − 四阶平均修正)，可以比 p_solved 低，也可以高。blast wave 128² 的实测（`pgap` 诊断）：非地板格子里 p_solved − p_true 最大 0.47（相对 0.14%）；地板格子里 p_solved = 10⁻⁷ 而 p_true ≈ 0.03；全程 94% 的 RK 级有格子停在地板上（激波前沿）。所以“pressure-positivity-preserving”对存储状态只是经验上成立（全程 p_true,min = 5×10⁻⁴），论文要把陈述限定到求解压力，并报告地板的激活频率。
5. **论文二表 1 的标题**：“t_f = 0.2”，正文说 t_f = 1；我用 t = 1 逐位复现了 ρ₀ = 1 这一行（3.06e-3、4.67e-4、6.23e-5、7.92e-6），标题错。另外 ρ₀ ≤ 10⁻⁴ 时 EOC 到 4.2–4.9，三阶格式出现超收敛，需要解释（误差被四阶空间算子主导、尚未进入渐近区），否则审稿人会问。
6. **论文二 4.1 节**：“The time step of the present method is restricted by a CFL condition based on the material velocity alone, with no dependence on the acoustic or Alfvén speeds”——与 (45) 矛盾：时间步按分裂谱 max|λ̃^c| 取，ε = 1 的区域里就是快磁声速；blast wave 全程 dt ≈ dt_MHD。只在 ε → 0 的算例（涡、KH、field loop）才是物质速度。
7. 参数不一致（不是数学错误，但审稿人会当作错误）：κ₁ = 0.4（论文）vs 0.05（代码）；blast wave 的 B₀、γ、初值平滑、CFL；论文一的 κ₁ = 10⁻³。

1. **不是修复 A / C**：256² 上原始给 213.7 / 0.00769，A+C 给 211.7 / 0.00591，逐项同阶；128² 同样。
2. **不是累积的能量漂移**：在塌掉的格子 (0.3008, 0.2305) 上放探针，压力到第 280 步还是精确的 0.100000，然后在**前沿经过的 2–3 步内**塌掉：

   | 0–280 | 0.100000 | 0.100000 | 0.100000 | 1.000000 | 19.74664 | 195.2148 |

3. **不是嵌入式 CT 丢掉的 Newton 余项**。`g_kembar` 用的是关于 Q_E 的切线性化 `kl(Q_E,Q) = m_E·m/ρ − |m_E|²/2ρ + B_E·B − |B_E|²/2`，精确值减它恰好是正定二次余项 `½|m−m_E|²/ρ + ½|B−B_E|²`，而嵌入路径（`emb_on`）的 Picard 循环一次都不执行（`for(ipic=1; ipic<(emb_on?1:g_npicard); ipic++)`），余项永不回收。用与 `kemb_lin` **完全相同的转换族**（不带限制器）测出的真实余项：每级范围 [0, 0.535]，累积范围 [0, 4.10]（确实正定 ✓），但在塌掉的格子里（p < 0.05，n = 232）平均累积只有 **7.45×10⁻⁴，是 7.23×10⁻² 亏损的 1%**。把它加回去（`eassm=1`，诊断版本）只改动 3.5×10⁻⁵。

   - 第一次尝试用 `cellavg_e_kemb`（**带**限制器的点值转换）替换时代码直接炸（divB = nan，密度保护触发 3.6×10⁷ 次）—— 因为那样混进了「带/不带限制器」两套重构之差，不是纯余项。

### 是什么

这个测试的 β 极低：B₀ = 70/√(4π) = 19.7466，磁压 m = |B|²/2 = 194.96，环境热压 0.1，所以

```
beta_amb = 2p/|B|^2 = 5.129e-4 ,   热能 p/(gamma-1) / E = 0.25/195.21 = 0.128%
```

即 `p = (γ−1)(E − KE − |B|²/2)` 是一个**灾难性相消**：总能上 0.2% 的相对误差（δU = −0.4）就能吃掉整个环境压力。第 297 步的分解完全对上：

```
|B| 上升 0.056%  ->  delta(|B|^2/2) = 19.75 * 0.011 = +0.2185
U   下降 0.007%  ->  delta U                       = -0.0134
delta p = 0.4 * (-0.0134 - 0.2185) = -0.0928  ->  p = 0.1 - 0.093 = 0.007   ✓
```

机制：**在快激波脚处，CT 重构的 B（curl₄ 作用在 HJ-WENO5-Z 输运的矢势 A 上）被压缩的位置，比守恒 HLLEM/WENO3 通量抬升 E 的位置提前了不到一个网格。** 两者是**不同的离散算子**（不同重构、不同阶、不同模板），在激波处必然有不到一格的相位/幅度失配；在 β = 5×10⁻⁴ 下这点失配就是 −93% 的压力误差。显式参考解不出这个问题，因为它用**同一个通量**同时演化 B 和 E，两条前沿天然同相（它的 p_min = 0.0982 ≈ 环境值，frac(p<0.05) = 0）。

这也解释了角向分布：0° 是平行激波（B_perp 不被压缩，失配无从产生），90° 只压缩一个分量，20°–45° 两个分量同时变化、失配最大。

### 修复 D（已实现，默认关闭）

```
p >= betafloor * |B|^2 / 2
```

### 根治的方向（未实现）

1. **让 B 的离散更新与 E 的在激波处一致**。例如在激波指示器 χ > 0 的格子里，压力提取改用守恒通量给出的 B（而不是 CT 的 curl₄A），CT 只用于保证 div B；或者把能量通量里用的磁能改成与 CT 场同一个离散。
2. **双能量 / 熵格式**（低 β MHD 的标准解法）：在 β < β_switch 的格子里直接演化 p（或熵）而不是从 E 反算。这份代码有现成的条件 —— 压力子系统**本来就直接解出 p_K**，`eassm` 那套管路也已经验证可用且稳定；缺的是只在低 β 格子里信任 p_K、并处理由此产生的能量不守恒。
3. 这个缺陷**两篇论文都有**（论文一更严重，到负压），所以它是三路分裂 + 总能量格式在 β ~ 10⁻⁴ 下的共性问题，值得作为论文二的一个诚实的 limitation 小节，而不是藏起来。

## 7. 还没解决的问题与建议

1. **1000² 的验证**：本机只能跑到 256²。两个修复的作用方向在 128² → 256² 上是一致的，但 256² 上修复 A 单独不够、A + B 还剩一点交界处毛刺；1000² 请用第 5 节的命令对照 `orig`/`fixA`/`fixAB` 三个运行，看内部 |u|² 沿 x = 0 的线图和 div u 的谱（`stripe_fft.py`，`metrics.py` 两个脚本都能直接读 `plt_*.vtk`）。修复 B 的两个阈值（√(Δp/p) 进入切换函数、4 邻居）是第一次尝试，没有调过；如果 1000² 上交界处的毛刺仍在，可以试 8 邻居或把 Δp/p 不开方（更保守）。
2. **隐式磁路径的耗散**：E10 说明磁通量全隐式时即使有压力 Laplacian 也会变差；磁预测子的 Laplacian 是 χ 门控的（κ₁ 代码取 0.05，论文 0.4），而 CT 之后的 B = curl₄A 与 Lorentz 力（四阶中心）没有耗散。如果修复 B 不够，下一步是让磁 Laplacian 的门控也响应 |Δm|/m，或在 Lorentz 力/感应通量里用 (1−ε_B) 加权的迎风面值。
3. **HLLEM 在强激波后的奇偶解耦**：已由修复 C 处理（第 6.1 节）；s_p 的阈值 0.5 和 4 邻居是第一次尝试，Orszag–Tang、rotor 这类有强激波的算例也应该用修复 C 复查一遍（原代码的 Orszag–Tang 1000² 图里可能也有同样的条纹）。
4. **论文文本**：blast wave 的 B₀/γ/初值平滑/CFL/κ₁ 要与代码统一（两篇都要改）；论文二应说明 HLLEM 的两处额外限制（熵反耗散关闭、包络加宽）以及压力子系统的激波耗散（如采用修复 A），并把“压力下界被触及”的说法与实际 p_min 核对。
4b. **低 β 下的压力提取（最重要的遗留问题）**：第 6.4 节的远场塌陷只被修复 D 的地板挡住，没有根治。根治要么让激波处 B 的离散与 E 的一致，要么在低 β 格子里直接演化 p/熵（双能量格式）。嵌入式 CT 丢掉的正定 Newton 余项虽然不是远场问题的原因，但在爆心内部累积到 4.10（压力单位），论文二应说明一句：`emb_on` 时 Picard 不迭代，余项不回收。
5. 代码一的 blast wave 翼区压力偏高 4–5 倍，是全场 Rusanov（s_max = |u|_max）的数值加热，论文一的图 13 应注意这一点（与 Balsara–Spicer 对比时翼区会偏亮）。
