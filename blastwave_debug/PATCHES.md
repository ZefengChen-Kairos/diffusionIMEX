## 决定性测量：IDP 路线还有没有命

完整 128² blast（618 步、2472 次压力解、约 $10^7$ 次单元更新，senv=2, $\kappa_1=0.4$）：

```
U^L inadmissible: rho in 0 cells, p in 909 cells
density point-value guard applied 0 times
entropy anti-diffusion limited at 194832 faces
envelope widened at 0 faces
```

**读法：**

1. **$U^L$ 密度 0 个不可容许** → 低阶更新从不产生负密度，支撑 IDP 的引理经验成立。
   **密度方向的凸限制 $U=U^L+\theta(U^H-U^L)$ 可行。**
2. **$U^L$ 压力 909 个不可容许** → 往一个不可容许的状态混合不可能恢复可容许性。
   **IDP 对压力无效**，压力必须留给保护 6。这不是退让，是测出来的边界。
3. **保护 1 与保护 3 在这个算例上零触发。** 保护 3 的零触发值得注意：
   `g_env_wide` 只在加宽**真的改变** $s_L,s_R$ 时才自增，所以 senv=2（fix E2 的
   局部物质速度地板）可能已经把包络撑够宽，**把保护 3 吞掉了**。正在用 senv=0/1 对照验证。
4. **保护 2 触发 194832 面**（约占全部面-步的 1%）→ **承重**。

## 逐条判决

### 保护 2 + 3：真正 ad-hoc 的一对，而且 IDP 原理上救不了

两者用同一个 $J=\lvert\rho_R-\rho_L\rvert/\min(\rho_L,\rho_R)$ 和同两个常数，
源码注释写明是为**同一个失效**存在的：低 Mach 区滞止点（OT 的 X 点，$\varepsilon_M=0$，
$u\to0$）分裂包络是 $O(\lvert u\rvert)\to0$，通量无耗散，而隐式算子是中心型的——
**质量方程在那里没有任何耗散来源**，网格尺度密度结构一直长到点值失效。

**为什么 IDP 救不了**：IDP 往 $U^L$ 混合，而在那里 plain HLL 的包络同样是
$O(\lvert u\rvert)=0$，$s_L=s_R\to0$ 连 HLL 通量本身都退化。$U^L$ 不比 $U^H$ 更耗散。
2+3 做的是**制造两者都没有的耗散**，这超出限制器的能力范围。

**有原则的替代（论文里已有这个机制）**：论文 `eq:mag_stab` 是 $\chi$ 门控的 Laplacian。
它盖不到这个情形的原因很具体——$\chi>0$ 要求
$$h\,\nabla\!\cdot\!\mathbf u<-\kappa_1 c^{\min},\qquad c^{\min}=\sqrt{a^2+c_B^2},$$
而低 Mach 区 $a\gg\lvert u\rvert$，所以 $h\lvert\nabla\!\cdot\!\mathbf u\rvert\sim\lvert u\rvert$
永远打不过 $\kappa_1a$，**$\chi$ 在那里从不触发**。把 $\chi$ 改为门控在
**分裂谱半径 $\lvert\tilde\lambda^c\rvert_{\max}$** 上（显式算子真正解析的那个速度），
则 $\kappa_1\lvert\tilde\lambda^c\rvert\sim0.4\lvert u\rvert$ 与
$h\lvert\nabla\!\cdot\!\mathbf u\rvert$ 同量级，**恰好在那里触发**。

一行改动；用论文自己的机制和自己的 $\kappa_1=0.4$ 替掉两个 $J$-keyed 补丁和它们的
两个常数；而且它比现状**更自洽**：指示器本该门控在它所稳定的那个算子的速度上，
而不是门控在一个被送进隐式求解器的速度上。

### 保护 1：可以换成有名字、无可调常数的限制器

```cpp
if(!(rho_pt >= 0.5*rho_bar)) rho_pt = rho_bar;
```

位置在**反卷积算子内部**（四阶 FV 用 $\bar q\pm d^2\bar q/24$ 在均值与点值间转换），
不是更新里。IDP 碰不到它：IDP 保证**均值**可容许，而这个管的是从可容许均值
插出来的**点值**——即使均值完美，$\bar\rho+d^2\bar\rho/24$ 在 $\rho$ 剧变处仍可为负。
这是插值假象。

**替代**：连续缩放而非 0/1 开关，
$$\rho_{\rm pt}=\bar\rho+\theta\,\frac{d^2\bar\rho}{24},\qquad
\theta=\min\Big(1,\ \frac{\bar\rho}{\lvert d^2\bar\rho/24\rvert}\Big)\ \text{当增量为负},$$
即 Zhang–Shu 缩放限制器。**那个 0.5 直接消失**，只缩放必要的量（设计阶保得更好），
而且可引文献。本次 blast 里它零触发，所以不是承重项。

### 保护 4 + 5：不是可容许性补丁

- **4 `g_eps_basis_min=1e-2`**：**任意选择的重构基底**的条件数地板。源码有实测
  （`Final_emb_omp_original.cpp:168-173`）：$\varepsilon_M=10^{-2}$ 时完备性误差 $10^{-13}$、
  $\lvert L_5\rvert\sim10^{2..3}$；$10^{-6}$ 时误差 $10^{-7}$、$\lvert L_5\rvert\sim10^{7..8}$；
  $\le10^{-10}$ 时误差 $O(1)$、$\lvert L_5\rvert\sim10^{15..19}$（基底数值上已死）。
  $\kappa(R)\sim\varepsilon^{-4}$。**论文里已经写了这条**（§3.1 与 §3.3）。
  原理上可去：$\varepsilon_M\to0$ 时分裂通量就是纯输运，任何基底都可用于重构，
  换成一致良条件的基底（例如非分裂 MHD 基底）即可完全去掉地板。
- **5 `g_char_fallback_tol=1e-6`**：完备性自检，在**真实退化**（$B_n$ 比 $B_\perp$ 低约六个
  数量级）时回退到分量式重构。实测（2084–2088）：$B_n=O(1)$ 时误差 6e-14…3e-12，
  只在那个角落到 2e-6。标准做法。
  - **顺带一个代码问题**：2100 行注释描述了一个 `g_weno3_no_fallback` 开关，说那个
    "过保守"的 1e-6 判据已经退休、只守 NaN/Inf——但**这个变量在源码里根本不存在**，
    2106 行的 `err > g_char_fallback_tol` 仍在无条件生效。注释与代码不一致。

## 结论

**六个里：**

- **3 个能真正去掉**：保护 1（无参缩放限制器）、保护 2+3（重新门控 $\chi$，一个机制替两个补丁）。
- **2 个不是补丁**：保护 4、5 守的是真实数值退化与基底条件数，有实测支撑，4 已写进论文。
- **1 个你决定保留**：保护 6。

**"零可调可容许常数"可以达到。"零保护"不行，也不该**——4 和 5 守的是数值退化，不是建模漏洞。

**而 fix G（IDP 凸限制）不是那个"一个方法论解决全部"的答案**：它对密度可行（$U^L$ 零次不可容许），
对压力无效（909 次），对保护 2+3 所解决的问题原理上无能（$U^L$ 与 $U^H$ 同样无耗散）。
它能替掉的是"密度正性"这一条，而那一条在本次 blast 里**本来就没触发过**。

## fix I 不破坏收敛阶（一个被数据推翻的预测）

我先前预测重新门控会把阶封在二阶：光滑流里 ${\rm div}\,u\sim u/L$，
原门控的分母 $0.4c_f\approx0.4a\gg u$ 使 $\chi\equiv0$，
而新门控的分母 $\sim0.4u$ 使 $\chi\sim h/L\ne0$，Laplacian 项 $O(h^2)$。

**实测推翻了它。** 低 Mach 涡 $\rho_0=10^{-2}$（$M_c=0.14$，$\varepsilon_M\approx0$，
即新旧门控真正不同的区域），CFL 0.2，EOC(32→64)：

| | chisplit=0 | chisplit=1 | 误差比 N=32 / N=64 |
|---|---|---|---|
| $\rho$ | 3.55 | 3.52 | 0.995 / 1.017 |
| $u$ | 2.89 | 2.89 | 1.000 / 1.000 |
| $p$ | 3.19 | 3.29 | 1.014 / 0.948 |
| $B_x$ | 3.52 | 3.52 | 1.000 / 1.001 |
| $A_z$ | 3.64 | 3.64 | 0.999 / 1.001 |

**无法区分。** 我漏掉的是 $\tilde\chi=\min(1,\max(0,-h\,{\rm div}\,u/(\kappa_1c)-1))$
里的 $-1$：$\chi>0$ 要求比值**超过 1**，不是非零。光滑涡里比值 $\approx2.5h/L$，
N=32 时 0.78、N=64 时 0.39，都 $<1$ → $\chi$ 仍恒为 0。
而 OT 有电流片，比值能过 1，所以 chisplit=1 在那里确实触发（C 在步 548 即与 A 分开）。
**这正是想要的选择性：光滑处静默，结构处起作用。**

注：$\rho_0=1$ 的涡测不出任何差别，因为它超声速（$M_c=1.473$），
$\varepsilon_M=\varepsilon_B=1$ 使新门控**退化成原式**。第一次跑的是空测试。

## 结论更新

- fix I（$\chi$ 重新门控）：**安全**（不破坏阶、光滑处不触发）、**有选择性**（OT 里触发）。
- fix J（缩放限制器）：**零风险**（它守的那个保护在两个算例上都从不触发）。
- 保护 2+3：**在可测分辨率下证不出必要性**。删除前需要一次 512²/1024² 的 OT 确认。

# fix I 被证伪（OT 128², C 组）

```
C  jguard=0 chisplit=1
  rho: min=nan max=nan      p: min=nan max=nan
  density point-value guard applied 125093841 times    (A 与 B 都是 0)
  压力解 7872（A/B 是 9872）
```

**解全是 NaN。** 不是退化，是彻底摧毁。密度点值保护触发 1.25 亿次，
约占全部机会的 40%。

## 原因定位到具体几行

fix I 为了避免除零加了这个"精确极限"：

```cpp
if(!(denominator > 0.0)){   // [fix I]
    shock_eta_tilde(i, j) = (div_u < 0.0) ? 1.0 : 0.0;
}
```

Orszag–Tang 有**磁零点**（$\Bb=0$）和滞止点。在 $\varepsilon_Ma^2$ 与
$\varepsilon_Bc_A^2$ 同时趋零处分母为零 → $\chi$ 被设成 1 → 全强度
Laplacian → 磁预测器大面积抹平 → 密度反卷积失去正性 → NaN。

**那个极限我取反了**：「没有可解析的波速」应当意味着指示器无意义（$\chi=0$），
而不是满额触发。

低 Mach 涡的 EOC 测试没有抓到它，因为 $\rho_0=10^{-2}$ 的涡几乎处处 $\Bb\ne0$，
$\varepsilon_Bc_A^2>0$ 使分母始终为正。**一个光滑算例通不过的测试，
在有零点的算例上才暴露。**

## 最终判决

| 保护 | 判决 | 证据 |
|---|---|---|
| 1 `rho_guard` | **换成缩放限制器**（fix J） | blast 三种 senv 与 OT 的 A/B 上全部零触发 → 零风险 |
| 2 `ent_lim` + 3 `env_wide` | **留在代码里，写进论文** | 128² 上拿掉只差 0.2%、质量无损；但它们是为 1024² 的实际失效而加，而 $J>0.5$ 的频率强依赖分辨率 |
| 4 `g_eps_basis_min` | 不动 | 重构基底的条件数地板，论文已写，有实测 $\kappa\sim\varepsilon^{-4}$ |
| 5 `g_char_fallback_tol` | 不动 | 真实退化（$B_n$ 低六个数量级）时回退到分量式，标准做法 |
| 6 压力地板 | 不动 | 作者上篇文章的创新点 |
| **fix I** | **证伪，不进干净版** | OT 全 NaN |

**「补丁能不能全去掉」的答案是：不能。** 一个可以换成有原则的、可引文献的限制器；
两个必须留，但可以被**正确描述**而不再是补丁——
$J=\lvert\Delta\rho\rvert/\min\rho$ 是无量纲、无尺度的面间相对密度跳，
光滑流里 $J=O(h)$ 使两个机制随加密自动失活（实测 128² 上只触发 0.01% 的面），
欠分辨接触面上 $J=O(1)$ 才起作用；这与 MP/WENO 的限制器常数同类，不是物理调参。
两个不是可容许性补丁，一个是作者自己的贡献。

## 读法

**`none` 给了指标判别力**：完全不用 flattener 时 $\rho$ 峰值过冲 10%、≤8格 功率从 1.0% 升到 1.5%。
所以这不是摆设，指标也不是噪声。

**L1 = L2 = L3** 到四位有效数字 → `hllemcap`（$\delta_k\le1-0.25$）与**压力跳传感器**
各自都**可以整个删掉，没有可测影响**。cap 当初的理由是"在 flattener 不活跃的激波下游
保留一部分 HLL 耗散"，而 $\sigma$ 含跳变项后那里本来就活跃了。

**L1–L3 相对 ref 损失约 8% 锐度**（$\lvert\nabla\rho\rvert$ 0.970 vs 1.054，rms divu 掉 2.4 倍），
原因是它们把**包络加宽**也挂在 $\sigma\ge\chi$ 上 —— $\chi$ 是压缩探测器，
在激波处到处为正，于是每个压缩面都加宽包络，这是 ref 没有的新耗散。

**L4 把包络改为只挂跳变**，锐度回来一点、≤8格 最好（0.9%），但局部极值噪声明显变差
（$p$ 从 25.9% 到 33.9%）—— 是**压力跳留在包络里**造成的。

**L5 删掉压力跳，七个指标全部追平 ref 到四位有效数字。**

## 结论：统一是精确的

$$\sigma_\delta=\max\big(\chi,\ \Theta(J)\big),\qquad
\sigma_{\rm env}=\Theta(J),\qquad
J=\frac{\lvert\Delta\rho\rvert}{\min(\rho_L,\rho_R)},\quad
\Theta(J)=\min\big(1,\max(0,2J-1)\big)$$

$$\delta_k\leftarrow(1-\sigma_\delta)\,\delta_k,
\qquad (s_L,s_R)\ \text{按}\ \sigma_{\rm env}\ \text{退回}\ \texttt{eq:einfeldt}\ \text{的经典包络（受时间步速度封顶）}$$

| | 机制数 | 可调常数 | 质量 |
|---|---|---|---|
| 现状 | 4（$\chi$ flatten、压力传感器、guard 2、guard 3、cap） | 6（0.5 / 0.5,1 / 0.5,1 / 0.25） | — |
| **L5** | **1** | **2**（一个无量纲斜坡的两端 $J_0=1/2$, $J_1=1$） | **七项全部吻合到四位有效数字** |

**ref 的四个机制一直在做一个机制的事。** 三处引用全部已在论文里：

| 动作 | 依据 |
|---|---|
| $\delta_k$ 退回 HLL | Dumbser–Balsara 治 carbuncle 的做法，论文 `\cite{HLLEM}` |
| 包络退回经典 Einfeldt 估计 | 论文 `eq:einfeldt`，`\cite{einfeldt1991godunov}` |
| $\chi$ | Balsara flattener，论文 `eq:chi`，`\cite{Balsara2012}` |

$J$ 无量纲、无尺度：光滑流里 $J=O(h)$ 使整个机制随加密自动失活
（实测 128² 上 $\Theta(J)$ 只触发 0.01% 的面），欠分辨接触面上 $J=O(1)$ 才起作用。
