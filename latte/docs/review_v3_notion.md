## 2. 逐条判断

| # | 条目 | 判断 | 理由 |
|---|---|---|---|
| R1 | §1 证据边界、H1–H3 | 合理 | 假设和证据分得清楚，可以证伪。 |
| R2 | §2.2 入口契约 | 合理 | j_J 的定义扣除了截面自身的平移；这份契约正好可以当作 MPM→FVM 的单向接口。 |
| R3 | §2.3 无量纲化 | 正确 | 已逐个核对 μ*、p* 的量纲。 |
| R4 | §3 白化推导 | 正确 | Dc/Dt = (1/h)∇·(hD∇c) + s(1−c)/h；D=0 时的指数解和 T01 的闭式解 c=(m0+st)/(h0+st) 一致，已验算。 |
| R5 | E1+E2+E3 | 自洽 | 三式联立后，内部满足 Dρ/Dt=0。"气体不可压"的近似也可以量化：静压差约 ρgH ≈ 500 Pa，与 10⁵ Pa 相比体积变化约 0.5%。 |
| R6 | E5 μ 不随组分变化 | **有缺口** | 页面没规定 μ 是否依赖 C_B/C_M/C_G。如果咖啡、奶、奶泡共用一个 μ，那拟合出来的只是"等效混合黏度"。E4 说明奶泡黏度随含气率变化很大（具体数值我不确定）。这一点直接影响参数辨识。 |
| R7 | E7 号向 | 正确 | 凸液滴时 κ>0，可得 p = p_air + σκ + τ_nn。 |

| R9 | E8 无滑移 + 自由面 | **物理上不自洽，页面已承认** | 无滑移下的移动接触线存在 Huh–Scriven 奇点，结果依赖网格。做杯边测试前必须先定接触线模型。 |

| R11 | §5 入口 | 原则正确，**实现没有封版** | 垂向拉格朗日多层模型里 η 是单值的，表示不了埋在液面下的三维开放截面。可选方案：(a) 在表面局部开一块通量入口，修改运动学条件为 ∂tη+u·∇η−w=j_J，体积、组分、动量只进入顶层，压力取 p_air（这不是速度 Dirichlet，所以不违反 §5.2）；(b) 在入口处规定 η、压力用 Neumann 条件（§5.2 字面意思），但 Γ_J 与周围液面之间会出现高度台阶；(c) 局部三维参考解，代价最高。**(a) 是我的提议，Notion 里没有。** |
| R12 | §6.1 HB | 公式标准，门控合理 | ε 的归类见上表。 |
| R13 | §7.2 联合限制器 | 正确 | 只存两份组分时，第三份守恒的条件是每个面上的上游值之和等于 1，需要单独测。 |

## C. 新发现的问题
1. **时间线（最关键）**：CVPR 2027 的登记截止是 2026-11-11，正文截止 11-17，补充材料截止 11-24（均为 UK GMT 11:59:59）。今天是 10-28，离正文截止还有 20 天。项目进展里，"03 动力学核心实现与核验"仍是 Not started（原计划 10-19 完成），"05 校准与留出测试"计划 10-30 完成。V3 的整套 G0–G7，加上一个三维多层非静水求解器，要在约三周内、在只有 CPU 的环境里完成并写进论文，**我判断做不到**。范围必须由你来定。
2. **S2 诊断的证据强度**：D2（3×3 摆动包络）跑在 **n=64** 上，而 V0.5 自己的网格审计显示，384 与 768 之间的浓度 L1 差约 0.018，网格越细保留的细纹越多。n=64 的负结果没法区分"模型表达能力不足"和"数值耗散抹掉了细纹"。这反过来**支持 V3 先查数值和源项白化（H1、H3），而不是照 S2 的建议去加层身份或折叠**。V3 背离 S2 建议的理由是成立的。
3. **奶泡密度在接口两侧的约定**：三维倒奶 v0.1 的旧推定值是 ρ=800 kg/m³、σ=0.045 N/m、ν=1.5e-6 m²/s，并明确写着"微泡均匀化进入有效物性"。V3 的入口则是 C_M=1−φ_J、C_G=φ_J，ρ_M 指液体本身的密度。两边对接时，如果上游给的是均匀化密度 800、下游又设 φ_J>0，**含气量就算了两次**。接口必须二选一：要么用有效 ρ_M 并令 φ_J=0，要么用液体 ρ_M 并给出 φ_J。
4. **测试编号冲突**：V1 附录里的 T01–T05（rest、static tracer、translation、constant fraction、source limits）和 V3 的 T01–T17 编号相同、含义不同。代码和报告里需要加前缀加以区分。
5. **壁面条件随版本变化**：V0.5 和 V1 用阶梯近似的**滑移**壁，V3 改为**无滑移**。V3 已经写明这算作单独标记的边界变化，与旧版对照时必须分开记录。
6. **FluidLab 基线本身就是 MPM**（FluidEngine 加 LatteArt 环境）。如果你说的"MPM"指的是这个，它在 Notion 里的定位是**基线**，不是我们的倒奶模块。
