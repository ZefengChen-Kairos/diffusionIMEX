# 拉花模拟器 V4：阶段一结果报告

**结论先行。** 一组方程、一份共享物理参数（`PhysParams()`），只换**拉花缸能倒出来的**动作轨迹（§5），
产出六种图案的逐阶段形成过程。守恒每步断言通过，相对误差 ~1e-14。门禁结果见 §2；与参考视频的比较
在矫正-对轴后的公共坐标系里进行（§5b）。

相对任务书的闭合修改（全部六图共享，每处都有对照实验，详见 `docs/MODEL.md` §3）：

1. **压力闭合**用任务书备选形式 K_s/2·(h²−h₀²)，K_s = ρ_c g。主选浮力形式在纯咖啡区压力为零，发生"铲雪"（F1）。
2. **入射闭合**把留表率拆为非穿透份额 r（sigmoid，v_e = 0.80 标定）与奶泡产率 φ_f = 0.14；液态奶并入底液。按任务书起始标定，白区 5 s 淹没 79% 杯面（F2），摆动无条纹（F3）。
3. **体相回流只带回打发奶**；回流全部奶会把条纹间隙和切线冲白（F4）。
4. **最后一笔标定**：C_E 0.5 → 0.3，高位汇宽下限 3.5 → 2 mm；拉穿只过前缘约 8 mm 并在移动中收流（F5）。
5. **射流水平速度取缸嘴出口值** v_h = k_h v₀ ê + v_p（k_h 0.30 → 0.40 换算），不随落差增大；任务书形式把每个高位拉穿的尾端卷成"蘑菇帽"（F7）。
6. **冲击区几何"正置"**：白环移到坑外（r0_fac 1.5）、变窄（σ_d,fac 0.45），上涌收到坑缘（σ_r,fac 1.2）——叶脉、条纹前凸弧、心形中轴因此归位（MODEL §3.2b）。

两处**试过并退回**的修改（证据在案）：层厚交换（旧输入时代的补丁；现实倒法下任务书原模型本来就复现视频白区史线，交换反而毁掉沟壑自愈与层持久性，F6 + MODEL §3.3）；泡沫 Bingham 屈服与浮层模量 K_s/4（MODEL §3.3b、§3.1b）。

## 4. 失败分析

### 4.1 G1.3 冲击点棕洞（O3）未复现（0.98 → 0.84，机制已定位）

实测：低位驻留 Q=9 时缸嘴正下方 α = 0.84（冲击几何"正置"前为 0.98），棕色开口仍只在缸嘴后方的马蹄缺口处。

机制定位（MODEL §3.2b）：真实冲击区从内到外是"射流柱芯（棕）—坑缘上涌（棕）—奶泡浮出环（白）"三圈。
把白环移到坑外（r0_fac 1.5）、上涌收到坑缘（σ_r,fac 1.2）后，轴心的白色来源只剩弹性回填：
周围白层在 ∇h 驱动下以 ~σ_k/τ_relax 的速度向薄处回流，始终快于贴缘上涌把轴心染棕的速度。
继续加大 r₀、收窄 σ_r 会让每次落点出现可见的"甜甜圈"瞬态（视频里没有）。要在轴心维持棕色，
需要射流柱"占位"（柱芯处表层被物理排开、由上涌体相持续置换）——这是垂直结构，单层模型装不下，
留给阶段二的 MPM 入射数据（R 的空间分布直接测出）。

### 4.2 G3.2a 高位拖拽的质心位移 0.05 mm（自定阈值 0.5 mm）

任务书判据是"高位时旧斑仍被拖拽（质心位移 > 0）"；0.5 mm 是验收方案自行加严的阈值，按旧的宽核几何标定。
冲击区几何"正置"（MODEL §3.2b）后，高位细流的 E/R 搅动与 τ_j 牵引都集中在 ~2–3 mm 宽的一条线里：
线内材料被强烈拖动并拉出 11–13 mm 的白尾（G1.7 心尖、G3.2b 高位几乎不添白 ✓），但整块旧斑的质心
几乎不动（0.05 mm）。"拖拽存在"的物理内容由白尾与 G3.4 的通量分解继续证实；质心位移这个度量在
线状相互作用下失去分辨力，保留 FAIL 并如实记录，不为凑数回调阈值。

## 5. 动作：拉花缸能倒出来的倒法（`actions/scripts.py`，`docs/MODEL.md` §5）

![pours](figures/pours.png)

*图 7：六个图案的输入。左：流量 Q(t)；中：缸嘴高度 h(t)；右：缸嘴路径（深色 = 低位作画，灰 = 抬高细流）。竖线是笔画（批次）边界。*

旧版动作是分段常数/线性段：流量在 0 和 12 ml/s 之间瞬间开关，笔画之间 Q = 0、缸嘴直线滑到下一笔起点，
拉穿时缸嘴在 0.4 s 内从 1.2 cm 跳到 10 cm；之后又用进化策略把这些数字拟合到参考帧的白色轮廓，把动作推得更不像手。
这些拉花缸都倒不出来。新版：

| 项 | 旧版 | 新版 |
|---|---|---|
| 流量 | 每段常数，段间 Q = 0，开关瞬时 | 落嘴到收尾一股流不断；作画 10–12 ml/s，两笔之间收细到 3 ml/s；\|dQ/dt\| ≤ 31 ml/s² |
| 高度 | 1.2 cm ↔ 10 cm 跳变 | 作画 1 cm，两笔之间与拉穿抬到 5 cm；\|dh/dt\| ≤ 0.15 m/s |
| 位置 | 段间直线滑移（速度不连续） | C¹ 连续；引导路径加速度 ≤ 2.1 m/s² |
| 拉穿 | 10 cm、3 ml/s、0.6–0.9 s | 5 cm、4 ml/s、1.4–1.6 s，流量在移动和上抬中收到零，手随后减速停下 |
| 时序 | 手调 + 轮廓拟合 | 按视频字幕与 2 fps 帧（MODEL §5 表） |
| 倒入量 | 45–75 ml | 71–132 ml（≤ 150 ml） |
| 检查 | 只查可行盒 | 可行盒 + 手的限制，六个图案及其镜像都在 `tests/` 中检查 |

换成可倒的动作后，模型暴露了两处原先被短倒流掩盖的闭合问题，都以六图共享的方式修改（§3 F6、F7）：
1. **白区不再饱和**：`rim` 层厚交换下，大白心白区随倒流线性增长到杯面 61%，视频在 5 s 后停在约 43%。改为就地下潜（`local`）。
2. **拉穿尖端卷成蘑菇帽**：任务书的水平速度 k_h v_j 随落差增大，抬高拉穿时前冲推力是缸嘴移速的 8 倍。改为缸嘴出口速度 k_h v₀。

## 6. 参数与可辨识性

共享参数见 `docs/MODEL.md` §4。相对任务书起始值，标定改动的有：v_e 1.05 → 0.80，新增 φ_f = 0.14，C_E 0.5 → 0.3，σ_k,min 3.5 → 2 mm，Φ_* = 1.2 kg/m²，V_bulk0 = 180 ml。
γ、χ、k_h、ν_s、C_t、v_c 和其余核族系数都保持任务书起始值。

已知的可辨识性陷阱：
- φ_f 与 Φ_* 之间有尺度规范自由度。这里固定 Φ_*，用白区增长率标定 φ_f：大白心实测 293 mm²/s，视频约 350 mm²/s。
- v_e 与 φ_f 耦合：低位沉积 ∝ φ_f·r(v_e)。v_e 由"低位仍有约 20–40% 穿透"（棕色隔带、条纹）单独钉住。
- C_E 同时作用于低位（条纹隔带）与高位（拉穿）。σ_k,min 只作用于高位细流，用来分离这两种作用。
- γ 由停流 e 折时间约束：实测 0.18 s，判据 0.1–0.5 s。

## 8. 敏感性表

由 `python -m gates.sensitivity` 生成（N=96，细网格 288²），同存 `docs/SENSITIVITY.md`。
G1 指标取自 3 s 低位驻留（Q = 9）：白区增长率 dA/dt、棕洞宽、形心前移、停流 e 折时间；
G2 指标取自千层心摆动段（a = 9 mm, f = 1.5 Hz）：条纹数、中位间距、对比度。

要点：
- **v_e 仍最敏感**：−30% 时低位几乎全穿透，白斑长不出；+30%（接近任务书 1.05）条纹消失（与 F3 一致）。
