# 第一阶段：FVM 杯内液体求解器 —— 设计与假设记录

依据：Notion《V3 · 拉花物理模型》§1–§17（规格版本 `v3_proposal_2026-10-28`；§18 开发记录按要求未读）。
本阶段范围 = V3 的 G1–G3 软件关卡（T02、T03、T05–T17），外加两项我补充的波动色散验证（W01、W02）。
用户决定（2026-10-28）：不复现 V0.5 基线（G0、T01、T04 记为 not_run）；倒奶模型改为 MPM（不影响本阶段，
只影响入口接口，见第 6 节）。

## 1. 状态与网格

* 水平：均匀笛卡尔列（dx, dy），圆柱杯用阶梯掩码；垂向：N 层地形跟随（σ）层，平底 z = 0，
  界面 z_{k+1/2} = S_{k+1/2} · D(x, y, t)，D 为局部液深，即自由表面 η = D（单值）。
* 每个单元保存：材料体积 V、组分体积 V_B、V_M（V_G = V − V_B − V_M 由单纯形得到，V3 §4.2）、
  质量 M、动量 P = M v（单元中心，三分量）。
* 每个面保存：投影后的绝对体积通量 U（侧面 x/y、层间界面、自由面）。
* 压力 π 在单元中心，规范 p_air = 0。

## 2. 一个时间步（V3 §7.4 的一阶分裂参考）

1. 在步中点取入口状态，用同一组求积点给出体积、组分、质量、动量到达率（V3 §5.1）。
2. 用上一步投影过的无散面通量移动自由面：D^{n+1} = D^n + Δt (W_s + j)/A（列积分形式的运动学条件）。
3. 用**相对**面通量（侧面 Δt·U；层间界面 Δt·W − A S ΔD；自由面只有入口流入）同时输运体积、组分、
   质量、动量（V3 §7.2：一份面通量用于所有材料，F_ρ = Σρ_j F_j，动量通量 F_ρ v_f）。
4. 新几何上隐式黏性（后向 Euler）。
5. 新几何上一次共同压力求解：自由面 Dirichlet p = σκ，面通量精确投影；单元速度用面平均的
   净加速度（重力 + 压力）修正（与 Basilisk centered.h 同构）。
6. 检查（范围、液体分数下界、散度误差、有限性）；任何失败整步回滚；数值类失败 dt 减半重试，
   输入/几何类失败不重试（V3 §15）。

## 3. 关键离散

**压力与黏性算子（`operators.py`）。** 对 ∫ c|∇φ|² dV 在 σ 坐标中写成面项 + 棱项的平方和：
侧面差分（沿层）、界面差分（真竖直导数）、棱上的斜率交叉项 −2 z_x φ_x φ_z + z_x² φ_z²。
每个侧面把一半体积分给上下两条棱，按 Jensen 不等式 Q ≥ Σ W_e (a_e − z_e b_e)² ≥ 0，
所以算子**按构造对称半正定**（有 Dirichlet 面时正定）。压力用 c = 1/ρ，黏性用 c = μ。
已验证：L 对称到 1e-17，最小特征值为正；对 φ = z 的侧面通量精确为零（无 σ 坐标压力梯度误差）。

**材料输运（`transport.py`）。** 低阶 = 供体单元组分；高阶 = 通量限制的 Lax–Wendroff
（默认 Superbee，V0.5 同款），**每个面一个 φ，取三组分最小值**，因此各组分反扩散通量之和恒为零；
再用**选择性联合 FCT**：只在违反允许界的单元的面上施加标准 Zalesak 因子（同样是三组分最小值），
逐步扩大直到不再违反；最坏情况退化为全 Zalesak（可证有界）。不做任何 clamp/重新归一化。

**入口（`inlet.py`）。** 交接截面 Γ_J（椭圆，均匀或抛物速度剖面，可平移/倾斜），j = −(v_J − w_J)·n ≥ 0。
总量（体积、组分、质量、动量）由截面上的极坐标 Gauss 积分精确给出；分配到液面列用**与网格对齐的子格采样**
（每列 8×8 点竖直投影到截面平面、判断是否在椭圆内），再用一个全局因子把子格总量对齐到精确积分
（因子 = 1 + 子格边界求积误差，约 1e-3）。早期的“极坐标样本直接落列”会在大足迹下产生点阵状混叠
（内部列误差可达 30%），已弃用为默认。落在杯外 → OUT_OF_SCOPE（不重新归一化），截面离液面超过
connect_tol → GEOMETRY_INVALID，unknown → INPUT_INVALID（不当作 0），不跨状态变化插值，求解器不跨事件时刻步进。

**入口边界条件（按 V3 §5.2 字面）。** 覆盖率 ≥ 50% 的列组成入口“补丁”：补丁上的液面面为**规定通量面**
（到达材料的绝对法向通量 Σ v_J·n dA），压力由投影确定（Neumann）；其余液面为 Dirichlet p = σκ。
到达材料的体积、组分、动量通量进入顶层单元。自由面始终用上一步投影过的同一份面通量更新（GCL 精确），
所以补丁随截面运动（滞后一步）。旧的“液面通量 + 补丁处 p = p_air”（原 A1）保留为对照选项
`inlet_bc: surface_flux`，**已证实不物理**：射流动量无法在液面处建立滞止压力，被自由面泄掉，形成持续长高的鼓包。

## 5. 已知数值性质与问题

1. **入口与自由面的连接（G4 待封版，最重要）**：补丁随截面而非随周围液面运动，补丁边缘形成台阶；
   射流较快时坡度超过 1 → OUT_OF_SCOPE。T15：V3 合成参考入口（d = 0.04, U = 1, g* = 1）在 n=64/128 下分别于
   t ≈ 0.09 / 0.036 停止；慢速入口（d = 0.2, U = 0.1）和宽入口（d = 0.6, U = 0.01）可跑完 t = 1。体积/液位收支在所有
   运行中都精确（≤ 1e-12）。
2. **V3 合成参考入口的 Froude 数为 5**，滞止深度尺度 U²/2g = 0.5 大于杯深 0.25，本身就超出单值自由面可表示范围。
3. **非分裂输运的横风扩散**：对角平移的圆盘出现垂直于流向的形状畸变；T06 圆盘 L1 收敛阶约 0.5，光滑场约 1
   （Superbee 削峰）；T07 反向涡回位误差收敛阶约 0.5。改进方向：角点输运（CTU）或多维限制器。
4. **自由面层的度量一致性误差**：对 φ = z，自由面那一层的竖直通量有 O(坡度² · s_top) 相对误差
   （坡度 0.26、N = 6 时 0.8%，坡度 0.05 时约 1e-4）；非均匀层下内部界面也有 O(坡度² · Δs)。均随竖向加密收敛。
5. 单元中心速度的近似投影在墙边一阶（与 Basilisk 相同）；用于输运的面通量精确无散（e_div ~ 1e-15）。
6. 入口子格映射：部分覆盖的边缘列误差 3–5%（sub = 8），sub = 16 时 0.4–1.7%。
7. 性能（4 核 CPU、无 GPU）：完整一步约 0.25 s @ 16k 单元；纯输运 0.11 s @ 65k 单元；T07 (256², 8192 步) 约 28 分钟。
8. 动量账本：输运部分精确守恒（簿记残差 ~1e-16）；压力修正为近似投影，不逐位守恒总动量（墙反力未单独积分）。

## 6. 与 MPM 的接口（为下一阶段预留）

求解器只消费 `SurfaceSource`（每列的体积/组分/质量/动量到达率），它由求积样本
{x_q, dA_q, j_q, v_q, C_q} 聚合而来。MPM 适配器只要把越过交接截面的粒子转成这些样本即可；
目前是单向（MPM → FVM）。三维倒奶 v0.1 指出低位接触可能需要双向耦合，这一点仍待决定。
