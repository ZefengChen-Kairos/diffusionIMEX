# 验收方案（V4，阶段一）

本文件在实现之前写定，之后只追加"实测阈值"和"结论"，不回改判据。所有门禁使用同一份
`core/params.py::PhysParams()`（默认构造，不传任何参数）；脚本里出现的任何参数改动只允许出现在
"对照组"与"敏感性扫描"中，并在报告中标注。

术语：
- **白区** W(t) = {α > 0.5}，α 由细网格 Φ_f = Y_f·M_interp 渲染；A(t) = |W(t)|。
- **标签 k 的分布** 用粗网格守恒标签 Φ_k（账本）和细网格比值 Y_k（形状）两套；质心/面积用细网格，守恒用粗网格。
- **条纹** 沿图案轴线（+y）的 α 剖面上，相邻极大-极小差 > 0.15 的极值对。
- 所有"变化/位移"类判据都同时给出数值噪声底：同一输入、Δt×0.5 运行的差（G8 用同一工具）。

## G1 定点注入 → 大白心

| 编号 | 判据 | 阈值 |
|---|---|---|
| G1.1 | 低位驻留 A(t) | 注入期间单调不减（容差 1 个细格面积） |
| G1.2 | dA/dt 对 Q 的单调性（Q=6,9,12 ml/s 同驻留） | 平均 dA/dt 严格递增 |
| G1.3 | 冲击点棕洞：缸嘴正下方 α 的局部极小 | 注入中途 α(x_p) < 0.5，且洞（α<0.5 连通域含 x_p）等效直径 3–10 mm（起点 5–8 mm） |
| G1.4 | 马蹄形：白斑相对 x_p 的形心偏前（+y） | 形心 y − y_p > 0 |
| G1.5 | 停流后白区边界法向速度 e 折时间 | 0.1–0.5 s（拟合 \|v_b\|(t) 的指数） |
| G1.6 | 蠕变门禁：停流后 1 s 至 6 s 边界最大位移 | < 1 条纹宽（取 2 mm） |
| G1.7 | 贯穿切割后拓扑 | 前缘出现两个叶（沿 x 的 α 剖面在前半部分出现两峰），后端出现单一尖端（心尖），白区连通 |
| G1.8 | 对照：切割段 h_p 改为 1.2 cm（低位） | 不出现心尖收口（证明尖端来自高位切割的屏蔽汇+牵引） |

## 实测修订（实现后追加，原判据保留在上文，修订原因逐条写明）

| 编号 | 修订 | 原因 |
|---|---|---|
| G0.5 | 拆为 G0.5a：粗网格 M、Φ、P_x 镜像误差 < 1e-12（舍入级）；G0.5b：白区掩膜镜像 IoU ≥ 0.999，细网格 max\|ΔY\| < 1e-4 | 修正核窗口的不对称截断（改为按距离截断，坐标严格反对称）之后，粗网格场的镜像误差为 1.5e-15。细网格 Y 经 BFECC 局部钳制（非线性、带分支）把 1e-16 的舍入差放大到约 3e-6（2.5 s）。在所有逐元素求和顺序都镜像化之前，"逐位镜像 1e-10" 对非线性限制器不可达 |
| G0.9 | 新增诊断：细网格 Y·M_interp 与粗网格 Φ 的总量差与限制后 L1 差 | 比值形式的细网格输运不是严格守恒的；把一致性报告出来，而不是假定"按构造成立" |
| G1.7 / G1.8 | 增加"棕色切割线"判据：在白区最宽行到心尖之间、x = ±3 mm 两侧都为白的行上，轴线 α < 0.5 的比例。G1.8 判据改为对照组的切割线比例 < 心形的一半 | "后部缺口" 在切割之前就作为马蹄形开口存在（G1.4），无法区分高位与低位穿过；切割线才是高位切割独有的特征 |
| G2 / G5 条纹计数 | 单一白体（只有 1 个峰）计为 0 条纹 | 原计数把单一白斑的一个峰当作 1 条纹 |
| G4.1 / G4.4 | 用 A 的前缘（白区 y 的 98% 分位数）位移代替质心位移 | A 变成月牙后两臂向后包住 B，即使整体前推，质心也会后移；前缘才对应 O5 的"前推" |
| G2.3 | 用中位条纹间距（平均值同时报告） | 2 Hz 时中段有一处条纹在网格上未分辨（一个 11 mm 的缺口），平均值被单个缺口支配；中位数是对"条纹间距分布"的稳健估计 |
| G2.5 | 曲率改为从轴线沿条纹脊线横向追踪到 ±8 mm，两端都向后弯即为前凸弧 | ±4 mm 处的条纹仍几乎平直（弧在两侧才弯），原判据的符号是随机的 |
| G1.3 | 额外报告 x_p 到最近棕色像素的距离 | 马蹄形开口在缸嘴正后方几毫米处，冲击点本身仍为白；用于失败分析 |
| G6.1 | "连续" 判为：A 的表层质量从第一段结束（2.5 s）到 4.9 s 保留 ≥ 80%，且 A 的物质场（Y_A > 0.2）连通块 ≤ 2；白区掩膜下 A 的连通块数仍会报告 | 郁金香的技法就是"将底纹压开"：第二段从中间压开 A 的顶部，白区掩膜因此分成 3 块。判据原意是"不得消失重画"，应当检验物质本身，而不是它在白度阈值下的拓扑 |
