# 验收方案（V4，阶段一）

本文件在实现之前写定，之后只追加"实测阈值"和"结论"，不回改判据。所有门禁使用同一份
`core/params.py::PhysParams()`（默认构造，不传任何参数）；脚本里出现的任何参数改动只允许出现在
"对照组"与"敏感性扫描"中，并在报告中标注。

术语：
- **白区** W(t) = {α > 0.5}，α 由细网格 Φ_f = Y_f·M_interp 渲染；A(t) = |W(t)|。
- **标签 k 的分布** 用粗网格守恒标签 Φ_k（账本）和细网格比值 Y_k（形状）两套；质心/面积用细网格，守恒用粗网格。
- **条纹** 沿图案轴线（+y）的 α 剖面上，相邻极大-极小差 > 0.15 的极值对。
- 所有"变化/位移"类判据都同时给出数值噪声底：同一输入、Δt×0.5 运行的差（G8 用同一工具）。

## G0 守恒 / 空载

| 编号 | 判据 | 阈值 | 对照 |
|---|---|---|---|
| G0.1 | 静止无输入 1000 步：max\|u\| | < 1e-12 m/s（严格零，因纯咖啡 P_s≡0 且通量全为 0） | — |
| G0.2 | 带非均匀组分的静止初态（预置一块 Y=1 奶泡圆盘，Φ 无扰动）1000 步 | max\|u\| 有界、无棋盘格（相邻格速度符号交替比例 < 5%） | κ=0 时棋盘格指标（应显著更差，证明 κ 是必要的） |
| G0.3 | 单脉冲注入（0.5 s, Q=10 ml/s, h=1.5 cm）后：总质量、奶材料、各标签、动量账本 | 每步相对误差 < 1e-6，全程累计 < 1e-9·步数 | — |
| G0.4 | 空移缸嘴（Q=0，按树叶轨迹移动 6 s） | 所有场与初值逐位相同 | — |
| G0.5 | 镜像输入（x→−x）→ 输出镜像 | 细网格 Y 场 L∞ 差 < 1e-10（逐位镜像的离散格式） | — |
| G0.6 | 网格加密 128→192（细网格 384→576）大白心 | 白区 IoU ≥ 0.85，图案类别（心形分类器）不变 | — |
| G0.7 | 正值性 | 全程 M ≥ 0.3ρ_c h₀, 0≤Φ≤M, 0≤Φ_k≤Φ（粗网格，逐步检查） | — |

## G1 定点注入 → 大白心

| 编号 | 判据 | 阈值 |
|---|---|---|
| G1.1 | 低位驻留 A(t) | 注入期间单调不减（容差 1 个细格面积） |
| G1.2 | dA/dt 对 Q 的单调性（Q=6,9,12 ml/s 同驻留） | 平均 dA/dt 严格递增 |
| G1.3 | 冲击点棕洞：缸嘴正下方 α 的局部极小 | 注入中途 α(x_p) < 0.5，且洞（α<0.5 连通域含 x_p）等效直径 3–10 mm（起点 5–8 mm） |
| G1.4 | 马蹄形：白斑相对 x_p 的形心偏前（+y） | 形心 y − y_p > 0 |
| G1.5 | 停流后白区边界法向速度 e 折时间 | 0.1–0.5 s（拟合 \|v_b\|(t) 的指数） |
| G1.6 | 蠕变门禁：停流后 1 s 至 6 s 边界最大位移 | < 1 条纹宽（取 2 mm） |
| G1.7 | 贯穿切割后拓扑 | 前缘出现两个叶（沿 x 的 α 剖面在前半部分出现两峰），后端出现单一尖端（心尖），白区连通 |
| G1.8 | 对照：切割段 h_p 改为 1.2 cm（低位） | 不出现心尖收口（证明尖端来自高位切割的屏蔽汇+牵引） |

## G2 水平摆动 → 千层心

| 编号 | 判据 | 阈值 |
|---|---|---|
| G2.1 | 摆幅 a=0 对照 | 条纹数 = 0 |
| G2.2 | a=7.5 mm, f=2 Hz | 条纹数 ≥ 4 |
| G2.3 | λ 对 v_rel/f 的单调趋势（f=1.5, 2, 3 Hz 三组） | 平均条纹间距随 v_rel/f 单调增加（Spearman ρ=1） |
| G2.4 | 条纹对比度 10 s 衰减 | 停流后 0→10 s 对比度下降 < 30% |
| G2.5 | 曲率：条纹为前凸弧 | 条纹中心线拟合二次项系数符号一致（弧向前方开口或闭合一致） |

## G3 高 / 低位切换

| 编号 | 判据 | 阈值 |
|---|---|---|
| G3.1 | 同轨迹仅改 h_p（1.5 cm vs 10 cm） | 积分留表质量比 ≥ 10× |
| G3.2 | 高位穿过已有白斑：旧标签质心位移 | > 0.5 mm（被拖拽），而 ∫Φ 增量 ≤ 留表量（≈0） |
| G3.3 | E 的材料移除 vs Φ 账本 | 两者差 < 1e-9（同一个数，按构造） |
| G3.4 | 分离 C_t / C_E：同 (1−r)ṁ 下 C_t=0 与 C_E=0 两组 | C_t=0 时拖拽位移显著减小（<50%）；C_E=0 时收拢量（切割线两侧白区向中线位移）显著减小 |

## G4 推推乐

| 编号 | 判据 | 阈值 |
|---|---|---|
| G4.1 | 第二段注入后标签 A 质心前移 | > 2 mm |
| G4.2 | A 形变为月牙：A 的面积质心落在 A 的凸包之外或 A 的"内弧"包围 B 的质心（B 质心到 A 的角度覆盖 > 180°） | 角覆盖 > 180° |
| G4.3 | A/B 隔带：沿轴线剖面 A 与 B 之间 α 极小 | 存在 α<0.6 的极小（棕色隔带宽度 > 0） |

| G4.5 | A 标签总量 = 注入 A − ∫E·Y_A + ∫R·Y_b,A | 相对误差 < 1e-9 |
