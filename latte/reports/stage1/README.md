## 本阶段发现、需要你知道的问题

1. **原 A1 入口方案（液面通量 + p_air）不物理，已撤回。** 对照显示射流动量被自由面泄掉、形成持续长高的鼓包。
   改用 V3 §5.2 字面方案（规定法向速度 + Neumann 压力）。
2. **入口—自由面连接仍是开放问题（V3 G4 待封版）。** 补丁随截面运动，与周围液面之间出现台阶；快射流下坡度 > 1。
3. **V3 合成参考入口（U = 1, g* = 1, d = 0.04）Froude 数 5**，滞止深度尺度 U²/2g = 0.5 > 杯深，几百分之一秒就超出可表示范围。
   G4 之前需要重新定一组在模型范围内的合成入口参数。
4. **输运的横风扩散**（非分裂 + 逐面一维限制器）：对角流中锐利界面收敛阶约 0.5。这对“细纹保存”直接相关，
   建议在 G4/G5 前改为角点输运（CTU）或多维限制器。
5. 其余已知问题见 `../../docs/stage1_design.md` 第 5 节；所有自加假设见第 4 节（A1' – A7）。
